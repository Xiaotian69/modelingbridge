# 01 项目定位与边界说明

## 1. 项目基础定位

项目暂定名：ModelingBridge / 模桥

一句话定位：

> 面向大学生的 AI 引导式数学建模学习平台，用步骤化引导帮助学生从读题、数据、模型、代码、图表到论文表达逐步完成学习闭环。

核心口号：

> 让数学建模不再遥不可及。

产品类型：

- 公益教学入口
- 半自动 AI 工作台
- Python 实战训练
- 比赛辅助工具

第一阶段统一口径：

- 这是学习平台，不是论文代写平台。
- 这是比赛辅助工具，不承诺比赛结果。
- AI 的作用是引导、解释、拆解、检查和提供结构化建议。
- 学生必须在题型、数据、模型和论文表达等关键节点进行人工确认。

## 2. 目标用户

| 用户类型 | 典型状态 | 核心痛点 | 第一版对应能力 |
| --- | --- | --- | --- |
| 第一次参加数学建模的新生 | 不知道建模完整流程 | 看不懂题、不会拆小问、不知道下一步 | 学习路径、AI 拆题工作台 |
| 有 Python 基础但建模弱的同学 | 会写基础代码，但不懂模型 | 不知道模型为什么用、公式如何变代码 | 模型建议、代码框架、案例库 |
| 跨专业参赛者 | 数学或编程基础不均衡 | 概念断层、协作成本高 | 流程卡片、术语解释、工具箱 |
| 数学建模协会教学组 | 需要稳定教学材料 | 周末课内容难标准化 | 案例库、提示词库、教学流程 |
| 有参赛经验的同学 | 知道流程但效率不稳定 | 复盘难、检查遗漏、论文结构混乱 | 检验清单、图表建议、论文结构指导 |

## 3. 核心场景

| 场景 | 用户要完成的事 | 平台如何辅助 | 成功标准 |
| --- | --- | --- | --- |
| 新手第一次读题 | 理解题目要求和每一问目标 | 将题目拆成小问、输入、输出、约束 | 用户能说清每问要解决什么 |
| 比赛前训练 | 按流程练习完整建模路径 | 提供学习路径、案例和工具入口 | 用户能跟着流程完成一次演练 |
| 模型选择 | 从多个模型中选主线方案 | 给出基础模型、进阶模型、适用条件和局限 | 用户能解释为什么选这个模型 |
| 代码启动 | 将模型思路转成 Python 框架 | 提供代码骨架、函数划分和数据流说明 | 用户能开始写可维护代码 |
| 论文整理 | 把结果组织成论文结构 | 提供章节大纲、图表位置和检查清单 | 用户能形成自己的写作框架 |
| 协会教学 | 给新生做入门工作坊 | 用统一案例和步骤卡片组织课程 | 教学组可重复使用材料 |

## 4. 做什么

第一版明确支持：

- 题目拆解：识别题型、拆分小问、提取输入输出和约束。
- 数据需求：列出需要的数据字段、来源建议、是否必须和替代方案。
- 模型建议：给出基础模型、进阶模型、适用条件、局限和检验方法。
- 代码框架：提供文件结构、函数划分、伪代码或代码骨架。
- 图表模板：建议需要展示的图表、图注和论文位置。
- 检验清单：提醒稳定性、敏感性、误差和合理性检查。
- 论文结构指导：给章节框架、每节写作要点和结果表达模板。

## 5. 不做什么

| 禁止或暂缓事项 | 风险原因 | 推荐替代做法 |
| --- | --- | --- |
| 一键生成可提交论文 | 学术规范风险高，也不利于学习 | 只给论文结构、写作要点和检查清单 |
| 承诺获奖或承诺奖项等级 | 比赛结果不可控 | 对齐优秀论文标准，降低低级错误风险 |
| 替学生完成所有模型判断 | 模型选择必须理解题意和数据条件 | 给出方案对比，要求学生确认主线模型 |
| 虚构数据或文献 | 会直接破坏可信度 | 所有外部数据和文献标注“需人工确认” |
| 隐藏 AI 使用过程 | 不利于合规、复盘和教学 | 记录提示词、AI 输出和人工修改内容 |
| 自动外网搜数据 | 容易引入错误、过期或不可追溯来源 | 先提供数据需求表和人工确认流程 |
| 在线运行任意代码 | 存在安全和环境隔离成本 | 第一版只提供代码框架和本地运行建议 |

## 7. 对外介绍话术

### 路演版

ModelingBridge / 模桥是一个面向大学生的 AI 引导式数学建模学习平台。它不会替学生完成比赛论文，而是把读题、数据、模型、代码、图表、检验和论文表达拆成可学习的步骤。学生在每一步都能看到 AI 的解释和建议，并在关键节点进行人工确认，从而真正理解建模流程。

### 协会合作版

模桥适合作为数学建模协会的新生训练和周末教学入口。平台提供统一的学习路径、AI 拆题流程、提示词模板和教学案例，帮助教学组降低备课成本，也让新生能按照标准流程完成一次建模训练。平台坚持学习辅助定位，不提供可直接提交的终稿，也不承诺比赛结果。

### 用户版

如果你第一次看到数学建模题时不知道从哪里开始，模桥会一步步带你读题、拆小问、想数据、选模型、搭代码框架、规划图表和整理论文结构。它不会替你参赛，但会帮你把“看不懂、不会选、写不下去”的过程变得清楚。

## 8. 团队统一口径

每个成员需要能在 1 分钟内讲清：

- 项目是什么：AI 引导式数学建模学习平台。
- 服务谁：大学生建模新手、Python 基础同学、跨专业参赛者和协会教学组。
- 解决什么：读题、数据、模型、代码、图表、检验和论文表达中的断点。
- 不是什么：不是代写、不是保奖、不是自动生成可提交终稿。
- 第一版最核心是什么：AI 拆题工作台和学习路径。

## 9. 验收标准

- 团队成员能用同一口径解释项目。
- 外部同学听完不会误解为论文代写平台。
- 第一版范围不超过 5 个核心入口和 1 个核心 AI 流程。
- 所有高风险功能都有人工确认点或被明确延期。
