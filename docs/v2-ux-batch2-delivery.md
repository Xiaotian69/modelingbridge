## 完成内容（对应本批 7 项要求）

| 要求 | 实现 |
| --- | --- |
| 1. 精讲与专项练习闭环 | 精讲章末、页边“本节相关练习”、专题封面都能进入练习；练习反馈、帮助梯子都能回到对应小节；回程条带回原题 |
| 2. 精讲互动检查点 | 章内 4 道题改为检查点：按钮叫“核对”，即时反馈，可跳过，**不计成绩**；只记录“尝试过 + 最近结果”，与练习记录分开存放 |
| 3. 提交判分、首次答错不泄露 | 判分仍用已核验的 `grading.ts`；答错只显示错误类型与反例，并注明“不会直接显示标准答案”；第 2 次答错时“完整解析”标“推荐”，但不自动展开（Q7） |
| 4. 错题反馈、分层提示、知识点跳转 | 每道题有确定性的错因映射（只对能确认的错误给出诊断，其余明确说“无法确定原因”）；帮助梯子 启发 / 线索 / 完整解析 可跳级，均为课程预置内容；“回看：知识点 · 第 n 节”跳到对应小节并高亮 |
| 5. 回到原题恢复状态 | 草稿自动保存（300ms 防抖，离开页面立即写入）；回程条返回后恢复作答、尝试次数、上次结果、提示级别；刷新整页同样恢复 |
| 6. 与新框架一致、深浅主题、手机 | 精讲和练习页改用设计 token，退出旧样式区；交互图配色随主题切换；手机单列、目录折叠、题目下拉、底部固定“提交 / 帮助” |
| 7. 保护内容、ID 与本地数据 | `content.ts`、`questions.ts`、`grading.ts`、`solver.ts` 与核验数据未改动；7 个题目 ID、10 个小节 ID 不变；旧版本地记录自动迁移、原键保留并持续双写 |

## 本地学习数据（按迁移方案 02 实施的部分）

- 新键 `mb.v2.learning`（阅读位置、检查点、练习：尝试次数 / 最近结果 / 草稿 / 提示级别），`mb.v2.meta` 记录迁移时间。
- 首次加载时从 `mb_learning_reading_v1`、`mb_learning_practice_v1` 迁移；`think-1` 归入检查点；旧记录标“旧版记录”。**旧键不删除**。
- 每次提交、阅读位置变化同时写回旧键（双写），回滚到旧版本不会丢失 V2 期间的进度。
- 数据损坏时备份原文到 `mb.v2.learning.corrupt` 并从旧键重建；来自更新版本的数据只读不覆盖；浏览器禁止存储时进入内存模式并提示；多标签页按记录合并。
- 回程票只存在当前标签页的 `sessionStorage`，同一时间只有一张。
- 尚未做（第五步）：学习记录页的统一展示、分开导出 / 清空、从导出文件恢复。
