## 功能修改

- 用途、比赛和关键词可组合筛选，筛选条件保留在 URL；非法类型回退到全部；空结果清除筛选时保留有效的七关回程参数。
- 保留完整模板详情和实时预览，预览与详情复制共用文本生成逻辑；列表原文复制也包含用途、使用前提、限制和官方规则提醒。
- 示例只补空项，保留手工输入并标明示例来源；可选项留空显示“未提供”，必填项留空保留占位符并提示。
- 复制成功、示例未替换、必填项未填和失败分别反馈；失败时聚焦并全选手动复制文本。输入或模板变化后清除过期反馈，防止异步复制结果串到新内容。
- 校验旧缓存的值类型、变量键及来源标记，隔离模板草稿；存储写入被拒时使用当前页面会话内存回退。缓存异常不再触发 `trim` 错误。
- 七关公开题面预填随案例更新；手工修改的值保持不变；不把七关作答内容带入提示词。沿用现有入口和导出接口，无需修改七关业务实现。
- 使用现有主题变量和组件风格，新增样式限制在提示词模块；手机按钮触控尺寸与输入字号调整，保持桌面双栏 / 手机列表详情切换。
