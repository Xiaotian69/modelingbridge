## 课程

- `/learn/ahp`：10 节，从“三份实习怎么选”出发，依次讲层次结构、1–9 标度与判断矩阵、权重（特征向量 / 方根法 / 和积法）、一致性检验（λmax、CI、RI、CR）、层次总排序、Python 复现、局限与常见错误、自测、竞赛迁移。
- **判断矩阵实验**（第 5 节）：每对准则一个滑块，实时重算权重（幂迭代特征向量 + 方根法对照）、λmax、CI、RI、CR、通过 / 不通过、最矛盾的一对及其推算值、三份实习的最终排序；可切换 3 / 4 个准则；预设“小林的判断 / 完全一致 / 前后矛盾”。
- 层次结构图：桌面为 SVG，手机为分层列表；深浅主题均适配。
- 练习：2 个章内检查点 + 3 道自测 + 5 道练习（`/practice/ahp`），沿用同一判分引擎、错因诊断、三级帮助、回看知识点、回程条与草稿恢复。

## 数学验证

- 计算方法：最大特征值对应的特征向量用幂迭代求（正矩阵，Perron–Frobenius 保证收敛；相邻两次差 < 1e-12 停止）；λmax 取 (Aw)ᵢ/wᵢ 平均；CI = (λmax − n)/(n − 1)；CR = CI/RI，RI 用 Saaty（1980）表。
- 独立参照：`learning/ahp/verify_ahp.py` 用 `numpy.linalg.eig` 生成 `ahp-verified.json`（课程 8 个矩阵、层次总排序、总排序 CR、练习答案、200 个随机 3–7 阶互反矩阵）。测试逐项比对：课程矩阵 9 位小数一致；随机矩阵权重与 λmax 8 位小数一致，并检查 ‖Aw − λw‖ < 1e-9、λmax ≥ n。
- 课程示例 `examples/ahp_internship.py` 已实际运行：准则权重 (0.230, 0.648, 0.122)，CR 0.0032；总得分 A 0.366、B 0.421、C 0.213；总排序 CR 0.0142，与页面一致。
- 课程正文和表格中的数字均由代码从同一组判断计算生成，没有手写数值。
