## 完成内容

十节连续课程：原创生产问题 → 变量/单位/假设 → 资源约束 → 交互可行域 → 四顶点手算 → 可运行 Python → 灵敏度 → 整数反例 → 现实检验 → 自测与迁移。正文、题库、计算、渲染和本地存储分离。公式使用本地 KaTeX，代码高亮仅加载 Python。

图表允许调整两种利润、两种资源上限，显示最优方案、剩余工时、可行域顶点和等利润线；支持零资源、并列最优、整数生产。算法明确限于本章有界两变量模型。数据变化即时计算，不调用 AI，也不依赖后端。

题库含 1 道阅读思考、3 道章末自测、3 道递进专项，覆盖单选、多选、数值和判断。逐步提示、提交解析、数值容差、难度过滤、错题重练和本地学习记录均已实现。题目来源/核验说明/审核状态独立维护。开放题不自动评分。

阅读按“最近读到的小节”保存，可点击继续；不声称阅读位置等于掌握率。手机折叠目录、单列正文；支持键盘滑杆、原生表单控件、MathML、图表文字等价说明和减少动态效果。
