## 实现

- 九段首页：数学网络首屏、功能入口、学习路径、精选模型、教学案例、七关流程、工具指南、AI 状态、项目与共建入口。
- 五项主导航：首页、知识库、竞赛资料、闯关训练、工具箱。AI 独立入口；案例、赛事日历、记录等原有页面保留在首页或页脚。
- 手机折叠菜单，支持 Escape 关闭、点击导航关闭、切换桌面布局关闭、键盘焦点和跳到正文链接。
- 原生 Canvas 2D 球面数学网络：桌面 88 节点、窄画布 48 节点、鼠标附近响应、30fps 绘制上限、DPR 上限 1.5。屏外及标签页隐藏暂停，减少动态偏好下静态绘制；卸载清理帧、观察器和事件监听。
- 区块进入视口渐显、220ms 路由过渡、卡片与按钮反馈。动态效果遵守 `prefers-reduced-motion`。
- 非首页路由按需加载，提供加载与失败反馈。模型锚点与浏览器前进后退滚动恢复；异步案例正文加载完成后再恢复位置。
- AI 未开放状态明确显示，资源服务失败时明确无法下载。按钮加载时保留原有尺寸并阻止重复操作。
- 未修改七关数据格式、存储键、通关判定、教学内容和后端接口；未增加前端运行时依赖。

## 设计规范

`frontend/src/index.css` 为共享变量与组件样式来源：主文字 `#162d37`、深色首屏 `#0c222d`、阅读底色 `#f8faf9`、强调色 `#157a6e`、首屏按钮 `#91e4c8`。系统中文字体，无远程字体/CDN。基础间距 8/16/24/32px，主要区块间距桌面 72px、手机 48px；圆角 8/14/22px；普通交互 160/240ms，渐显 350ms。表单聚焦、禁用、按钮加载、错误和空/加载状态沿用统一配色。当前页面没有新增弹窗业务。

## 已知边界与下一阶段

1. AI 在线服务尚未开放；首页状态为当前版本明确的未开放说明，不是实时健康探测器。原有工作台仍保留后端接入能力，未来需统一服务状态来源。
2. 下载中心仍需后端，Phase 1 仅补充真实失败提示。静态竞赛索引、代码/可复制提示词库、公式与代码高亮属于 Phase 2，当前工具入口指向已有指南。
3. 原有案例详情可离线回退；从指定案例进入七关时，原训练页仍先请求 API，失败时使用默认题。此既有局限需在后续静态资料与训练升级中处理，本轮未改变训练逻辑。
4. 未部署 EdgeOne，也未进行中国大陆实网/真机性能验证。原 SPA rewrites、HTTPS 与域名配置保持不变。本轮深链接验证是本地 Vite 行为。
5. 浏览器检查了报告保存和导出按钮状态；没有把浏览器下载文件内容复核算作已执行的检查。系统字体在不同操作系统会略有差异。
6. 开发控制台有原项目 React Router v7 迁移提示，无须在本阶段升级路由库。
