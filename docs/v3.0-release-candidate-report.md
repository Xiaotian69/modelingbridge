### 5.3 偶发测试问题的修复

- 原因：`challenge_enter` 事件在 `useEffect`（passive effect）中发出；按需加载的页面在 `act` 之外提交，`findByRole` 可能在副作用执行前就拿到标题，此时 `events[0]` 还是空的。
- 修复：两处断言改为 `await vi.waitFor(() => expect(events[0]).toEqual(...))`，等待事件本身写入，期望值不变，没有削弱断言；页面代码不变。
- 验证方法不是重复运行：把页面中的事件人为推迟 50 毫秒，**旧断言每次都失败、新断言通过**；验证后已恢复页面代码。

### 5.4 教学内容一致性复核

- 三门新课逐节按页面实际文字重读（上一轮已改 9 处并加测试）。本轮重点区分：
  - **定理与假设**：如“最小二乘直线一定经过 (x̄, ȳ)”“度之和等于边数的 2 倍”“Dijkstra 需要非负权”是定理；“误差平均为 0”“直线关系只在数据范围内检验过”是模型假设，课文已分别说明。
  - **模拟与真实数据**：五门课的案例数据都标明“原创教学数据，不是真实记录”。
  - **预测与结论**：回归新增说明“R² 是这 14 天的拟合程度，拟合得好不等于预测新的日子同样准确；要用模型没见过的数据检验”；预测区间注明“建立在模型假设成立的前提下”；相关不等于因果单列一节。
  - **教学简化与严格算法**：图论的“n² 次比较”、“|t| 大于 2 左右”“每个自变量十来个观测”都写明是粗略估计或经验做法。
- 软化两处没有依据的绝对说法：“最常见的组合之一”→“常见的一种组合”；“画图永远是第一步”→“先画图，再计算”。
- **AHP 实验措辞**（V2.1 报告遗留第 3 项）：“前后矛盾”预设下三项权重都是 0.333，原文只点名两项；现在点名全部（“三个准则的权重几乎相同（都约为 0.333）”），先写测试再修改。

**发布**

```bash
git fetch origin
git ls-remote origin refs/heads/feat/edgeone-hk-pilot          # 应为 fecf178...
git tag backup/prod-2026-10-17 fecf178                          # 回滚点
```

EdgeOne 自动构建约 2 分钟上线。推送也会触发 GitHub CI 和 Vercel Preview（非生产）。

**回滚（EdgeOne 没有一键回滚，用 Git 前进式回滚，不强推）**

```bash

git checkout -B rollback/v3.0 origin/feat/edgeone-hk-pilot
git read-tree -u --reset fecf178
git commit -m "revert: roll production back to fecf178 (before V3.0)"
```
