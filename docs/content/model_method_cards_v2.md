## 卡 1：线性规划 / 整数规划（slug: linear-programming）

**家族**：优化 ｜ **层级**：入门

---

### 新手问答（5 组）

**Q1：我什么时候该用线性规划？**

A：当你能写出"在某些限制条件下，让某个目标尽量大或尽量小"这句话时，就可以考虑线性规划。例如：在运输成本限制下让总调度量最大、在预算限制下让覆盖面最广。关键词是：**决策变量有上下限**、**目标是线性函数**、**约束是等式或不等式**。

**Q2：LP 和 MILP 有什么区别，我该选哪个？**

A：LP（线性规划）的变量可以是小数；MILP（混合整数线性规划）的部分或全部变量只能取整数。选择原则：如果你的决策变量是"运多少辆车"或"开不开这条路线"，就用 MILP。如果是"流量比例"或"资源分配率"，LP 通常够用。MILP 计算量远大于 LP，题目允许近似解时优先用 LP。

**Q3：我怎么知道我的模型是否有解？**

A：用求解器求解后检查 `status`。PuLP 返回 `'Optimal'` 说明有最优解；`'Infeasible'` 说明约束互相冲突，没有可行解（最常见原因：供需不平衡——总供给 < 总需求）；`'Unbounded'` 说明目标函数没有上限或下限（通常是忘记加变量的非负约束）。

**Q4：什么是灵敏度分析，我一定要做吗？**

A：灵敏度分析回答的是："如果某个参数（成本系数、约束右端项）变化一点，最优解会变多少？"在竞赛论文中不是必须的，但强烈推荐：评委会问"如果成本涨了10%方案还成立吗"，你必须能回答。最简单的做法：把关键参数改变±10%，重新求解，对比结果。

**Q5：多目标优化怎么处理？题目要求同时最小化成本和最大化满足率。**

A：最常见的两种方法：① **加权求和**：把两个目标合成一个（`min α×成本 - β×满足率`），但权重 α/β 的取值需要在论文里解释；② **约束转化**：把其中一个目标变成约束（如"满足率≥90%"），再最小化成本。竞赛中方法②更容易解释和验证。

---

### 最小例题

**题目**：3 个仓库（库存分别为 50、80、60 单位），2 个需求点（需求分别为 90、100 单位），运输成本矩阵如下（元/单位）：

|  | 需求点 1 | 需求点 2 |
|--|---------|---------|
| 仓库 1 | 2 | 5 |
| 仓库 2 | 4 | 1 |
| 仓库 3 | 3 | 3 |

目标：最小化总运输成本，满足所有需求，不超过仓库库存。

**解题步骤**：
1. 决策变量：`x[i][j]` = 从仓库 i 运往需求点 j 的量（≥0）
2. 目标函数：`min Σ cost[i][j] × x[i][j]`
3. 约束：`Σ_j x[i][j] ≤ supply[i]`（库存）；`Σ_i x[i][j] ≥ demand[j]`（需求）
4. 检查总供给（190）> 总需求（190）→ 恰好平衡，有可行解

---

### Python 伪代码

```python
import pulp

# 数据
warehouses = [1, 2, 3]
demand_points = [1, 2]
supply = {1: 50, 2: 80, 3: 60}
demand = {1: 90, 2: 100}
cost = {(1,1): 2, (1,2): 5, (2,1): 4, (2,2): 1, (3,1): 3, (3,2): 3}

# 建模
prob = pulp.LpProblem("transport", pulp.LpMinimize)

# 变量（连续，非负）
x = pulp.LpVariable.dicts("x", [(i,j) for i in warehouses for j in demand_points],
                           lowBound=0)

# 目标函数
prob += pulp.lpSum([cost[(i,j)] * x[(i,j)] for i in warehouses for j in demand_points])

# 约束：库存上限
for i in warehouses:
    prob += pulp.lpSum([x[(i,j)] for j in demand_points]) <= supply[i]

# 约束：需求满足
for j in demand_points:
    prob += pulp.lpSum([x[(i,j)] for i in warehouses]) >= demand[j]

# 求解
prob.solve(pulp.PULP_CBC_CMD(msg=0))

# 结果
print(f"求解状态：{pulp.LpStatus[prob.status]}")
print(f"总成本：{pulp.value(prob.objective):.0f} 元")
for i in warehouses:
    for j in demand_points:
        if x[(i,j)].value() > 0:
            print(f"仓库{i} → 需求点{j}：{x[(i,j)].value():.0f} 单位")
```

---

### 论文写法要点

1. **变量表必须完整**：论文第一节就给出决策变量定义和单位，不要让读者在公式里猜。
2. **目标函数和约束分开展示**：不要把所有式子挤在一段文字里，用编号公式列出，每条约束后配一句现实解释。
3. **说明求解工具和版本**：例如"使用 Python PuLP 库（版本 2.7）调用 CBC 求解器"。
4. **结果表必须包含单位**：不要只写数字，"最优调度量 = 80"含义模糊，"最优调度量 = 80 辆次"清晰。
5. **灵敏度分析单独成节**：至少对最关键的1—2个参数（如运输成本或需求量）做扰动分析。

---

### 常见错误

1. **忘记供给约束**：只写"需求必须满足"，忘记"调出量不超仓库库存"，求解器会从空仓库无限调货。
2. **整数变量漏写**：调度的是整数（车辆、箱子），却用连续变量，得到如"调 2.7 辆"的无意义结果。
3. **多目标权重拍脑袋**：加权系数随意设定，评委问"为什么 α=0.3"答不上来。需要说明依据（AHP/专家判断/量纲归一化）。
4. **没有检验无可行解**：直接输出结果，没有检查 status，当约束不可行时输出乱数。
5. **约束列不完整就建模**：拿到题目先写变量和目标，约束想到哪写到哪，结果论文里的约束比代码里少，或者比代码里多。

## 卡 2：时间序列预测（slug: time-series）

**家族**：预测 ｜ **层级**：入门

---

### 新手问答（5 组）

**Q1：我的数据按时间排列，一定要用时间序列模型吗？**

A：不一定。时间序列模型（ARIMA、指数平滑）适合"数据主要受自身过去规律影响"的情况，比如销量有明显周期性或趋势。如果数据受多个外部特征影响（天气、节假日、促销活动），回归或树模型可能更合适，只要做好时序划分（不随机切分）即可。两者可以都做，比较哪个误差更小。

**Q2：ARIMA 的 p、d、q 怎么确定？**

A：三步走：① `d`：对序列做平稳性检验（ADF test），不平稳就做一阶差分，直到平稳，d 就是差分次数；② `p`：看 PACF（偏自相关图），找截断点；③ `q`：看 ACF（自相关图），找截断点。实在不确定，用 `pmdarima` 库的 `auto_arima` 自动选参数，但论文里需要解释选了什么参数及理由。

**Q3：时序数据为什么不能随机切分训练集和测试集？**

A：时序数据有时间顺序，随机切分会把"未来"的数据放进训练集，让模型在训练时"偷看"了未来，测试误差会虚假偏低。正确做法：前 80% 时间段用于训练，后 20% 用于测试（按时间顺序切分）。更严格的做法是滚动验证（rolling cross-validation）。

**Q4：MAPE 是什么，为什么有时候不适用？**

A：MAPE（平均绝对百分比误差）= 误差/实际值 的平均百分比。当实际值接近 0 时，分母很小，MAPE 会变得极大甚至无穷，失去意义。遇到这种情况改用 MAE（绝对误差）或 RMSE（均方根误差）。论文里推荐同时报多个误差指标，不要只给一个。

**Q5：我的预测结果要作为优化模型的输入，预测有误差怎么办？**

A：这是竞赛论文里非常值得讨论的点。处理方式：① 用预测的上界（如 95% 分位数）代替均值输入优化，偏保守但更安全；② 在优化模型中加入惩罚项（缺货比多货惩罚更重）；③ 在论文的"模型局限"节讨论"当预测误差为 X 时，优化结果的误差传递"。

### 最小例题

**题目**：某校区每天共享单车订单量（过去 14 天）如下：
`[120, 135, 98, 140, 155, 132, 90, 125, 138, 102, 145, 158, 130, 95]`
预测第 15—21 天（下一周）的每日订单量。

**解题步骤**：
1. 画时序图，观察趋势和周期（7 天明显周期？）
2. ADF 检验平稳性
3. 若有周期性，考虑季节性 ARIMA（p,d,q）×（P,D,Q,7）
4. 也可先用移动均值作 Baseline：第 15 天预测 = 前 7 天均值
5. 用最后 7 天作测试集，比较两个方法的 MAE

---

### Python 伪代码

```python
import pandas as pd
import numpy as np
from statsmodels.tsa.stattools import adfuller
from statsmodels.tsa.arima.model import ARIMA

# 数据准备
data = pd.Series([120, 135, 98, 140, 155, 132, 90,
                  125, 138, 102, 145, 158, 130, 95])

# 步骤1：平稳性检验
result = adfuller(data)
print(f"ADF p值: {result[1]:.4f}")  # p<0.05 说明平稳

# 步骤2：划分训练/测试（时间顺序，不随机）
train = data[:10]  # 前10天训练
test = data[10:]   # 后4天测试

# 步骤3：Baseline（移动均值）
baseline_pred = [train[-7:].mean()] * len(test)
mae_baseline = np.mean(np.abs(test.values - baseline_pred))
print(f"Baseline MAE: {mae_baseline:.2f}")

# 步骤4：ARIMA 模型
model = ARIMA(train, order=(1, 0, 1))  # 参数需根据ACF/PACF确定
fitted = model.fit()
arima_pred = fitted.forecast(steps=len(test))
mae_arima = np.mean(np.abs(test.values - arima_pred))
print(f"ARIMA MAE: {mae_arima:.2f}")

# 步骤5：比较，若 ARIMA 优于 Baseline 则有意义
# 步骤6：用全量数据重新训练，预测未来7天
final_model = ARIMA(data, order=(1, 0, 1)).fit()
forecast = final_model.forecast(steps=7)
print("未来7天预测:", forecast.values.round(0))
```

---

### 论文写法要点

1. **先写趋势与周期观察**：展示时序图，说明"数据有 7 天周期，整体无明显趋势/有上升趋势"。
2. **解释模型参数选择过程**：不是直接给 ARIMA(p,d,q)，而是说明怎么从 ACF/PACF 图或 AIC 准则确定参数。
3. **误差图比单个数字更有说服力**：画"真实值 vs 预测值"折线图，让评委看到预测在高峰和低谷是否准确。
4. **说明极端情况的局限性**：如"本模型假设未来天气与历史规律一致，暴雨等极端天气可能导致预测偏差"。
5. **误差传递到优化模型**：如果预测结果用于后续优化，必须讨论预测误差如何影响优化结果。

---

### 常见错误

1. **随机切分时序数据**：导致用未来数据训练，测试误差虚低，完全不代表真实预测能力。
2. **只建 ARIMA 不建 Baseline**：无法说明 ARIMA 比"直接用历史均值"好了多少，结论站不住脚。
3. **MAPE 在近零值情况下失真**：某些时段订单为 0，MAPE 无穷大，报"MAPE=∞%"没有意义。
4. **特征泄露**：构造滞后特征（lag-1, lag-7）时，测试集的 lag 值使用了测试集内的数据，模型"偷看"未来。
5. **不画残差图**：若残差有明显规律（如高峰时段总低估），说明模型有系统偏差，需要在论文里说明。

## 卡 3：回归 / 随机森林（slug: regression-tree）

**家族**：预测 ｜ **层级**：入门

---

### 新手问答（5 组）

**Q1：线性回归和随机森林我该用哪个？**

A：两者都用，先跑线性回归做 Baseline，再跑随机森林。如果随机森林的测试集误差比线性回归低很多，说明数据有非线性关系，进阶模型有意义。如果两者差不多，用线性回归反而更容易解释。竞赛论文中"对比 Baseline 的提升幅度"本身就是一个加分点。

**Q2：我的特征有数值型和类别型，要怎么处理类别型特征？**

A：类别型特征需要编码。常用方法：① One-Hot 编码（适合无序类别，如城市名）；② 标签编码（适合有序类别，如"低/中/高"）；③ Target Encoding（适合高基数类别，如区域编号，但要注意防止数据泄露）。随机森林对 One-Hot 编码处理较好，不需要标准化数值特征。

**Q3：特征重要性是怎么来的？我可以用它来解释因果关系吗？**

A：随机森林的特征重要性基于"去掉某个特征后预测误差增加多少"（Permutation Importance）或"该特征在决策树中的总分裂增益"。**不能直接说明因果关系**：特征 A 重要不等于 A 导致了目标变量的变化，可能是因为 A 和某个真正的原因 B 高度相关。论文里应该说"特征 A 对预测最有影响力"，而不是"A 导致了 Y"。

**Q4：什么是过拟合？怎么判断我的模型过拟合了？**

A：过拟合指模型在训练集上表现很好，在测试集上表现差。判断方法：对比训练集误差和测试集误差，若测试集误差是训练集的 2 倍以上，很可能过拟合。解决方法：减少特征数量、增大随机森林的 min_samples_leaf 参数、做交叉验证而非单次划分。

**Q5：交叉验证和普通训练/测试划分有什么区别，竞赛要做吗？**

A：普通划分只测了一次，结果可能受划分方式影响。K 折交叉验证做 K 次，每次用不同部分作测试集，结果更稳定。竞赛中建议做 5 折交叉验证（或时序滚动验证）来报误差，这样更有说服力。但如果数据量小（如 < 200 行），交叉验证尤其重要。

### 最小例题

**题目**：预测共享单车需求量。特征：小时（0—23）、星期几（0—6）、温度（°C）、是否节假日（0/1）。已有 100 行历史数据，前 80 行训练，后 20 行测试（按时间顺序）。

**解题步骤**：
1. 特征工程：把小时转为 sin/cos 周期特征（避免"23时和0时差很大"的问题）
2. 先跑线性回归 Baseline，记录 MAE
3. 再跑随机森林，对比 MAE
4. 输出特征重要性图，解释哪个因素影响最大
5. 检查残差是否有规律

---

### Python 伪代码

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error

# 假设 df 已有列: hour, weekday, temperature, is_holiday, demand
# 特征工程：小时的周期编码
df['hour_sin'] = np.sin(2 * np.pi * df['hour'] / 24)
df['hour_cos'] = np.cos(2 * np.pi * df['hour'] / 24)

features = ['hour_sin', 'hour_cos', 'weekday', 'temperature', 'is_holiday']
X = df[features]
y = df['demand']

# 时序划分（不随机）
split = int(len(df) * 0.8)
X_train, X_test = X[:split], X[split:]
y_train, y_test = y[:split], y[split:]

# Baseline：线性回归
lr = LinearRegression()
lr.fit(X_train, y_train)
lr_pred = lr.predict(X_test)
print(f"线性回归 MAE: {mean_absolute_error(y_test, lr_pred):.2f}")

# 进阶：随机森林（固定随机种子保证可复现）
rf = RandomForestRegressor(n_estimators=100, random_state=42)
rf.fit(X_train, y_train)
rf_pred = rf.predict(X_test)
print(f"随机森林 MAE: {mean_absolute_error(y_test, rf_pred):.2f}")

# 特征重要性
importance = pd.Series(rf.feature_importances_, index=features).sort_values(ascending=False)
print("特征重要性：")
print(importance)
```

---

### 论文写法要点

1. **用 Baseline 证明改进**：不要只说"随机森林 MAE 为 X"，要说"比线性回归 Baseline 低了 Y%"。
2. **特征解释不要越界成因果**：说"温度对预测需求贡献最大"，而不是"温度决定了用车需求"。
3. **随机森林需补充可解释性**：SHAP 图或特征重要性柱状图，帮助评委理解模型为什么这样预测。
4. **展示误差对业务指标的影响**：如"MAE=15辆意味着调度方案的成本误差约为 XX 元"。
5. **声明随机种子**：保证结果可复现，"固定 random_state=42"这一行必须在论文代码附录中体现。

---

### 常见错误

1. **把相关说成因果**：特征重要性高不等于因果，不能在论文结论里说"A 导致了 B"。
2. **只报训练集分数**：R²=0.99 听起来很好，但如果是训练集上的，可能是过拟合。
3. **特征泄露**：滞后特征用了测试集内的未来数据，或者用了目标变量本身的变换作为特征。
4. **特征重要性不稳定还硬解释**：多次训练结果中特征排序变化很大，说明重要性不稳健，不应该强行解读。
5. **类别变量未编码**：把"城市名"直接放进模型（sklearn 会报错或产生错误结果）。

## 卡 4：熵权法 / TOPSIS（slug: entropy-topsis）

**家族**：评价 ｜ **层级**：入门

---

### 新手问答（5 组）

**Q1：熵权法的"权重"是什么意思？它合理吗？**

A：熵权法的权重反映"该指标在不同对象间的差异程度"——差异越大的指标权重越高，因为它提供的信息量更多。这是一种**纯数据驱动**的客观权重，不需要专家打分。合不合理取决于场景：如果你希望权重反映数据差异，用熵权法；如果希望权重反映人类的价值判断，用 AHP。竞赛中两种方法都可以，要说明选择理由。

**Q2：效益型和成本型指标有什么区别？如何判断？**

A：效益型指标"越大越好"（如绿地面积、满意度）；成本型指标"越小越好"（如污染物浓度、等待时间、事故率）。判断方法：对每个指标问一句"这个值越高，评价对象越好吗"？如果是，效益型；如果不是，成本型。标准化方向写反是最常见的错误，直接导致排名完全错误。

**Q3：TOPSIS 的"接近度"是什么，能当分数用吗？**

A：接近度（记为 C*）衡量评价对象离正理想解的接近程度，取值 0—1，越接近 1 越好。**不能直接当百分制分数使用**：C*=0.8 不等于"80分"，它只是一个相对排名指标。论文里应该说"食堂 A 的综合接近度最高（0.82），在所有候选对象中综合表现最优"，而不是"食堂 A 得分 82 分"。

**Q4：为什么要做权重扰动分析？怎么做？**

A：权重扰动分析检验排名对权重假设的敏感性。因为熵权法或 AHP 给出的权重不是真理，稍有变化排名可能改变。做法：在原权重上加均匀分布随机噪声（如 ±5%），重新归一化，重新跑 TOPSIS，记录排名变化。重复 100—1000 次，统计每个对象的排名分布。若第 1 名在 100 次扰动中从不变化，说明结论非常稳健。

**Q5：我的某列指标所有值都一样（如全部城市的绿化率都是 30%），熵权法会怎么处理？**

A：如果某列指标所有值完全相同，熵值 = 1，信息量 = 0，熵权法会给这列指标权重 = 0（即完全不参与评价）。这在数学上是正确的，但要在论文里说明"XX 指标因为各对象无差异，未纳入权重计算"。编码时要注意避免除以零（加小量 ε = 1e-10）。

### 最小例题

**题目**：对 3 个食堂窗口综合评价，指标：等待时间（分钟，成本型）、口味评分（1—10，效益型）、价格（元，成本型）。

| | 等待时间 | 口味 | 价格 |
|--|---------|------|------|
| 窗口 A | 5 | 8 | 15 |
| 窗口 B | 8 | 9 | 12 |
| 窗口 C | 3 | 7 | 18 |

**解题步骤**：
1. 按效益型/成本型做标准化
2. 计算熵权
3. 加权后求正负理想解
4. 计算接近度，排名

---

### Python 伪代码

```python
import numpy as np

# 数据矩阵 (对象×指标)
X = np.array([[5, 8, 15],
              [8, 9, 12],
              [3, 7, 18]], dtype=float)

# 指标方向：True=效益型(越大越好), False=成本型(越小越好)
benefit = [False, True, False]

# 步骤1：标准化（效益/成本区分处理）
X_norm = np.zeros_like(X)
for j in range(X.shape[1]):
    x_min, x_max = X[:,j].min(), X[:,j].max()
    if x_max == x_min:  # 避免除以零
        X_norm[:,j] = 0.5
    elif benefit[j]:
        X_norm[:,j] = (X[:,j] - x_min) / (x_max - x_min)
    else:
        X_norm[:,j] = (x_max - X[:,j]) / (x_max - x_min)

# 步骤2：熵权法计算权重
eps = 1e-10
p = X_norm / (X_norm.sum(axis=0) + eps)
e = -np.sum(p * np.log(p + eps), axis=0) / np.log(len(X))
w = (1 - e) / (1 - e).sum()
print("权重：", w.round(3))

# 步骤3：TOPSIS
V = X_norm * w  # 加权标准化矩阵
v_pos = V.max(axis=0)  # 正理想解
v_neg = V.min(axis=0)  # 负理想解
d_pos = np.sqrt(((V - v_pos)**2).sum(axis=1))
d_neg = np.sqrt(((V - v_neg)**2).sum(axis=1))
C = d_neg / (d_pos + d_neg)

# 步骤4：排名
ranking = np.argsort(-C) + 1
print("接近度：", C.round(3))
print("排名：窗口", ranking)
```

---

### 论文写法要点

1. **指标体系先于公式**：先介绍为什么选这些指标（指标来源、覆盖维度），再展示公式。
2. **解释权重高低原因**：权重高的指标意味着它在各对象间差异最大，需要用语言解释这个现象是否合理。
3. **排名后必须给改进建议**：评价的目的不只是排名，而是"第 3 名在哪里表现最差，应该怎么改"。
4. **稳健性结果单独成节**：权重扰动分析的结论（哪些名次稳定、哪些不稳定）放在"模型检验"节，不要省略。
5. **接近度不等于百分制分数**：论文中说"接近度最高"或"综合优势最显著"，不要说"得分最高"。

---

### 常见错误

1. **指标方向写反**：成本型指标用了效益型公式，导致"污染越重排名越高"的荒谬结论。
2. **没有做稳健性分析**：排名接近的两个对象可能因权重微小变化而互换，不检验就强行说"A 优于 B"。
3. **接近度当百分制分数**：C*=0.7 不等于 70 分，这个误解在论文里很常见。
4. **权重没有解释**：给出了权重表，但没有说为什么某指标权重最高，评委会质疑。
5. **虚构问卷数据**：为了做 AHP 或主观权重，编造专家打分，这是学术不诚信问题。需要说明打分来源或用熵权法替代。

## 卡 5：AHP 层次分析法（slug: ahp）

**家族**：评价 ｜ **层级**：入门

---

### 新手问答（5 组）

**Q1：AHP 和熵权法的最大区别是什么？**

A：最大区别在于权重来源。AHP 的权重来自人类的主观判断（专家两两比较），反映的是"哪个指标更重要"的价值判断；熵权法的权重来自数据，反映的是"哪个指标差异更大"。AHP 适合有明确价值取向的决策（如政策评估）；熵权法适合数据驱动、主观因素少的评价。竞赛中两者结合使用（主客观权重平均或赋权组合）是高分写法。

**Q2：判断矩阵的一致性检验是什么？CR < 0.1 怎么理解？**

A：一致性检验检查"你的两两比较前后是否矛盾"。例如：你说 A 比 B 重要、B 比 C 重要，但又说 C 比 A 重要——这就矛盾了。CR（一致性比率）< 0.1 表示矛盾在可接受范围内。CR ≥ 0.1 时必须修改判断矩阵，不能继续使用。

**Q3：竞赛里"专家打分"怎么处理？我没有真正的专家。**

A：三种合规处理方式：① 用题目背景文献中提到的权重取值；② 说明"本文以问卷形式向10位数学建模经验丰富的同学收集意见"（协会成员可以算）；③ 用熵权法替代，避免主观权重的合法性问题。不要无中生有虚构"3位专家打分"。

**Q4：判断矩阵怎么填？1-9 标度是什么意思？**

A：标度含义：1 = 同等重要；3 = 稍微重要；5 = 明显重要；7 = 强烈重要；9 = 极端重要；2、4、6、8 为中间值。矩阵必须满足互反性：如果 A 对 B 的重要性为 3，则 B 对 A 必须填 1/3。填完矩阵后计算 CR，若 ≥ 0.1 需调整。

**Q5：AHP 可以用在有很多指标的情况吗？**

A：AHP 的判断矩阵是 n×n 的，指标数量 n 越大，两两比较的数量（n(n-1)/2 次）越多，人工填写越容易出错，CR 越难通过。一般建议同一层级的指标数量 ≤ 9。指标过多时，可以先把指标分组（准则层），每组内再做 AHP。

### 最小例题

**题目**：评价校园食堂，指标为：口味（A）、卫生（B）、价格（C）。三个指标两两比较判断：口味比卫生稍重要（3）、口味比价格明显重要（5）、卫生比价格稍重要（3）。计算权重，检验一致性。

**判断矩阵**：
```
A  B  C
A: 1   3   5
B: 1/3 1   3
C: 1/5 1/3 1
```

---

### Python 伪代码

```python
import numpy as np

# 判断矩阵（必须互反）
A = np.array([[1,   3,   5  ],
              [1/3, 1,   3  ],
              [1/5, 1/3, 1  ]])

# 计算权重（特征向量法）
eigenvalues, eigenvectors = np.linalg.eig(A)
max_idx = np.argmax(eigenvalues.real)
w = eigenvectors[:, max_idx].real
w = w / w.sum()  # 归一化
print("权重：", w.round(4))

# 一致性检验
n = len(A)
lambda_max = eigenvalues[max_idx].real
CI = (lambda_max - n) / (n - 1)
RI = {1: 0, 2: 0, 3: 0.58, 4: 0.90, 5: 1.12, 6: 1.24,
      7: 1.32, 8: 1.41, 9: 1.45}  # RI 查表
CR = CI / RI[n]
print(f"最大特征值: {lambda_max:.4f}")
print(f"CI: {CI:.4f}, CR: {CR:.4f}")
if CR < 0.1:
    print("✅ 一致性检验通过，权重可用")
else:
    print("❌ 一致性检验不通过，需修改判断矩阵")
```

---

### 论文写法要点

1. **解释层次结构**：画出目标层—准则层—方案层的层次图，让评委看清决策框架。
2. **说明专家来源或模拟假设**：权重来源必须有交代，即使是协会成员问卷也要说明。
3. **一致性检验必须出现**：必须明确写出 CR 值，CR < 0.1 是结论可信的前提。
4. **与客观权重对比**：将 AHP 主观权重与熵权法客观权重对比，讨论两者差异的原因。
5. **不要只报最终排名**：展示中间步骤（判断矩阵、各层权重），让读者能复现。

---

### 常见错误

1. **判断矩阵不互反**：A 对 B 填了 3，B 对 A 填了 2，而不是 1/3——矩阵不合法。
2. **CR 不合格还继续用**：CR=0.15 超标，继续使用该权重，论文结论不可信。
3. **主观权重伪装成客观结论**：用 AHP 得出结论，但没说明打分来源，让评委以为是客观数据。
4. **层次过多导致不可解释**：构建 5 层层次结构，底层权重乘积后评委完全看不懂。保持 3 层以内更清晰。
5. **只给综合排名不给各层结果**：评委看不出是哪一层级的权重差异导致了排名，论文说服力弱。

## 卡 6：聚类分析（slug: clustering）

**家族**：统计 ｜ **层级**：入门

---

### 新手问答（5 组）

**Q1：聚类和分类有什么区别？我的题目该用哪个？**

A：分类（Classification）是"有标签的学习"：你知道哪些样本属于哪类，训练一个模型预测新样本的类别。聚类（Clustering）是"无标签学习"：没有预先知道的类别，让数据自己形成自然分组。判断依据：题目数据有没有给"标签"（如"违约/未违约"、"通过/不通过"）？有标签用分类；没标签用聚类。

**Q2：K 值怎么选？肘部法是什么？**

A：肘部法：对不同的 K（如 K=2,3,...,10），计算簇内误差平方和（SSE），画出 SSE 随 K 的变化曲线。找曲线的"肘部"——下降变慢的转折点，该 K 值是较好的选择。轮廓系数（Silhouette Score）是另一个方法：对每个 K 算轮廓系数，越接近 1 越好。两个方法结合使用，选出最优 K，并在论文里解释"我选 K=3 因为肘部法和轮廓系数都支持这个选择"。

**Q3：为什么聚类之前必须标准化特征？**

A：K-Means 用欧式距离度量相似性。如果特征 A 的范围是 0—1000，特征 B 的范围是 0—1，距离计算会被 A 主导，B 几乎没有贡献。标准化（Z-score 或 Min-Max）让所有特征的量纲一致，距离计算才公平。规则：**只要特征量纲不同，就必须标准化再聚类**。

**Q4：聚类结果怎么解释和命名？**

A：不要随意给簇贴标签。正确做法：① 计算每类的各特征均值（簇中心）；② 分析各类在哪些特征上与其他类有显著差异；③ 用特征差异命名（如"高消费低活跃用户"、"低消费高活跃用户"）。名字必须来自数据特征，不能凭感觉编造。

**Q5：聚类结果怎么检验是否有意义？**

A：用三个角度检验：① **轮廓系数**（量化类内紧密度 vs 类间分离度）；② **不同 K 值的稳定性**（换不同 K 看聚类结果是否大幅改变）；③ **业务意义**（每类的特征描述是否有现实解释，是否能对应策略建议）。纯统计好看但没有解释的聚类，在竞赛里得分不高。

### 最小例题

**题目**：对6个城市按"人均 GDP（万元）"和"空气质量指数（AQI）"聚类：

| 城市 | 人均GDP | AQI |
|------|--------|-----|
| A | 12 | 80 |
| B | 8  | 120|
| C | 15 | 90 |
| D | 6  | 140|
| E | 14 | 85 |
| F | 7  | 130|

**解题步骤**：标准化 → 肘部法选 K → K-Means → 解释每类特征

---

### Python 伪代码

```python
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt

X = np.array([[12, 80], [8, 120], [15, 90],
              [6, 140], [14, 85], [7, 130]])

# 步骤1：标准化（必须）
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 步骤2：肘部法选K
sse = []
for k in range(2, 6):
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    km.fit(X_scaled)
    sse.append(km.inertia_)
# 画SSE曲线，找肘部（此处省略画图代码）

# 步骤3：轮廓系数
sil_scores = []
for k in range(2, 6):
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = km.fit_predict(X_scaled)
    sil_scores.append(silhouette_score(X_scaled, labels))
best_k = np.argmax(sil_scores) + 2
print(f"轮廓系数建议K={best_k}")

# 步骤4：最终聚类
km_final = KMeans(n_clusters=best_k, random_state=42, n_init=10)
labels = km_final.fit_predict(X_scaled)

# 步骤5：解释各簇特征（用原始数据）
cities = ['A','B','C','D','E','F']
for c in range(best_k):
    idx = np.where(labels == c)[0]
    cluster_data = X[idx]
    print(f"簇{c+1}（{[cities[i] for i in idx]}）:")
    print(f"  平均GDP: {cluster_data[:,0].mean():.1f}万, 平均AQI: {cluster_data[:,1].mean():.0f}")
```

---

### 论文写法要点

1. **先解释为什么要分群**：评价类题目分群是为了差异化策略，聚类不是目的而是手段。
2. **类名要来自特征而非想象**：用特征均值命名簇，而不是给出"优质城市""落后城市"等主观标签。
3. **策略建议对应每类特征**：对"高 GDP 低 AQI"类提一套建议，对"低 GDP 高 AQI"类提另一套，建议必须和特征对应。
4. **不要把聚类当监督分类**：聚类结果是无标签的，不能用聚类标签直接预测新城市"属于哪类"（那需要分类模型）。
5. **样本数量要报**：每类有多少样本，若某类只有 1 个样本，需要解释是否合理。

---

### 常见错误

1. **未标准化导致量纲支配**：GDP 量纲远大于比率型指标，K-Means 的距离被 GDP 完全主导，AQI 形同虚设。
2. **K 值没有依据**：直接选 K=3，没有做肘部法或轮廓系数，评委会问"为什么是3"。
3. **只画散点图不解释**：降维后可视化的散点图看起来有3堆，就说"有3类"，没有用原始特征解释每类含义。
4. **簇名随意贴标签**：给簇 1 取名"先进组"，给簇 2 取名"落后组"，没有用特征数据支撑。
5. **忽略离群点**：1—2个极端样本形成单独的簇，没有讨论这些异常点的含义。

## 卡 7：微分方程 / 机理模型（slug: differential-equation）

**家族**：机理 ｜ **层级**：进阶

---

### 新手问答（5 组）

**Q1：什么情况下才应该用微分方程，而不是用数据拟合？**

A：当题目的变量之间有**明确的物理/生物/经济机制**时，优先考虑微分方程。例如：传染病传播（感染人数的变化率=传染率×接触率）、人口增长（增长率正比于当前人口）、物体运动（力=质量×加速度）。如果只是"数据有规律但原因不清楚"，用数据拟合。机理模型的优势是可解释性强，参数有现实含义。

**Q2：SIR 模型是什么？什么题可以用？**

A：SIR 是传染病动力学模型，S（易感者）→ I（感染者）→ R（康复者），用三个微分方程描述三类人群的变化率。适合：传染病传播、谣言扩散（把"谣言"当"感染"）、产品扩散（把"购买者"当"感染者"）。使用前提：群体假设足够大（>1000人），个体行为相同。不适合：小群体、有明显异质性（不同地区传播率完全不同）的场景。

**Q3：微分方程的参数怎么确定？**

A：三种方法：① **从实验数据拟合**：给参数初值，用最小二乘法优化，让模型输出和实测数据的误差最小（`scipy.optimize.curve_fit` 或 `lmfit`）；② **从文献中找范围**：如 SIR 模型的感染率 β 在不同传染病中有典型范围；③ **假设并验证**：在论文中明确说明假设参数值及理由，再通过情景分析展示结论对参数的敏感程度。

**Q4：数值求解和解析求解有什么区别？我应该用哪个？**

A：解析求解：精确公式，如指数增长 `N(t) = N₀ × e^{rt}`。数值求解：用 `scipy.integrate.solve_ivp` 等工具逐步计算。竞赛中大部分机理模型没有解析解，用数值求解即可，不要浪费时间尝试手算。但需要在论文里说明数值方法的步长（dt）和精度。

**Q5：我的微分方程模型参数很多，是不是越复杂越好？**

A：不是。参数过多有两个问题：① 参数估计困难：数据量不够时，10个参数可能有无数组合都能拟合数据（过拟合）；② 解释困难：每个参数的现实含义说不清，论文说服力差。原则：**能用3个参数的模型解释数据，就不用8个参数**。从最简单的机理开始，按需增加复杂度。

### 最小例题

**题目**：某城市传染病传播，初始易感人口 S₀=10000，初始感染人数 I₀=10，康复率 γ=0.1（每天），传染率 β=0.0003（每天·人）。模拟30天内 S、I、R 的变化，画出曲线，并估计峰值感染人数和时间。

### 论文写法要点

1. **每个方程解释现实含义**：`dI/dt = βSI - γI` 后面跟一句"感染者增加量=新感染人数-康复人数"。
2. **参数表要完整**：列出所有参数的符号、含义、数值/估计方法、单位。
3. **用情景模拟支撑建议**：比如"如果 β 降低 30%（等效于戴口罩），峰值下降 X%"，这是论文建议的依据。
4. **承认机理简化**：说明"SIR 模型假设人群均匀混合，实际存在地区差异"，主动承认局限比被评委指出更好。

### 常见错误

1. **方程变量无意义**：写出一堆微分方程，但每个状态变量的现实含义说不清楚。
2. **参数全靠拍脑袋**：β=0.3 从哪来的？论文里没有说明，评委无法验证。
3. **没有单位检查**：方程左边是 dS/dt（单位：人/天），右边是 βSI（单位取决于 β 的单位），必须量纲一致。
4. **只拟合不解释机制**：模型拟合了数据，但参数的现实意义没有解释，退化成了"高级的曲线拟合"。
5. **自由参数太多**：8个参数的 ODE 拟合200行数据，参数之间高度相关，任何值都能拟合——结论无意义。

## 卡 8：网络流 / 图模型（slug: network-flow）

**家族**：网络 ｜ **层级**：进阶

---

### 新手问答（5 组）

**Q1：什么题型适合用图模型？**

A：当问题的对象自然形成"实体（节点）+关系（边）"结构时，考虑图模型。例如：路口和道路（交通）、仓库和运输路线（物流）、用户和社交关系（传播分析）、城市和航班（路径规划）。关键问题：我的对象能不能画成节点？对象之间的关系能不能画成有权重的边？

**Q2：最短路、最大流、最小费用流有什么区别？**

A：**最短路**：找从 A 到 B 总权重最小的路径（权重=距离/时间）；**最大流**：找从源点到汇点能流过的最大流量（受边容量约束）；**最小费用流**：在满足流量需求的同时，最小化总运输成本（最常用，是上面两个的综合）。竞赛里最常用的是最小费用流，对应物流调度、资源分配。

**Q3：networkx 怎么使用？是必须用它吗？**

A：networkx 是 Python 中最方便的图模型库，可以建图、算最短路、可视化。但它的求解器对大图可能较慢。选择依据：如果图有 < 1000 个节点，networkx 完全够用；如果更大，考虑 scipy.sparse.csgraph 或专业求解器。不是必须用它，但对竞赛来说是最快的实现方式。

**Q4：图太大怎么可视化？**

A：不要把所有节点都画出来。做法：① 只画关键子图（最优路径涉及的节点和边）；② 用节点大小/颜色表示中心性或重要性；③ 用热力图代替节点图（适合地理空间数据）。论文里不需要一张"让人看清楚所有节点的"图，只需要让读者看懂关键结论。

**Q5：什么是节点中心性？我什么时候需要它？**

A：中心性衡量节点在网络中的重要性。常用：度中心性（连接多少节点）、介数中心性（有多少路径经过这个节点）、接近中心性（到其他节点的平均距离最短）。用途：找交通网络中最关键的交叉路口（介数中心性高），或者传播网络中影响力最大的节点。大部分优化类题目不需要中心性，只有"识别关键节点"或"评估网络鲁棒性"时才用。

### 最小例题

**题目**：4个路口（A、B、C、D），5条有向边，边权为行驶时间（分钟）：A→B:3, A→C:6, B→C:1, B→D:7, C→D:2。求从 A 到 D 的最短路径和时间。

---

### Python 伪代码

```python
import networkx as nx

# 建图（有向图）
G = nx.DiGraph()
G.add_weighted_edges_from([
    ('A', 'B', 3), ('A', 'C', 6),
    ('B', 'C', 1), ('B', 'D', 7),
    ('C', 'D', 2)
])

# 最短路（Dijkstra）
path = nx.shortest_path(G, 'A', 'D', weight='weight')
length = nx.shortest_path_length(G, 'A', 'D', weight='weight')
print(f"最短路径: {' → '.join(path)}")
print(f"最短时间: {length} 分钟")

# 最小费用流（运输优化示例）
# 需要 nx.min_cost_flow，图需有 demand 和 capacity 属性
# 见 networkx 文档 nx.algorithms.flow.min_cost_flow

# 可视化（关键子图）
pos = {'A': (0,1), 'B': (1,2), 'C': (1,0), 'D': (2,1)}
edge_colors = ['red' if (u,v) in zip(path, path[1:]) else 'gray'
               for u, v in G.edges()]
nx.draw(G, pos, with_labels=True, edge_color=edge_colors,
        width=2, node_size=500)
labels = nx.get_edge_attributes(G, 'weight')
nx.draw_networkx_edge_labels(G, pos, labels)
# plt.savefig('shortest_path.png', dpi=150)
```

### 论文写法要点

1. **网络图只展示关键子图**：100个节点的完整图让人看不出结论，只展示最优路径或关键节点附近的子图。
2. **解释节点重要性指标**：介数中心性最高的节点意味着"断掉这个节点会影响最多路径"，要用一句话翻译给读者。
3. **情景分析比静态指标更有价值**：比如"删除最关键节点后，全网平均路径增加了 X%"，比只给出中心性值更有说服力。
4. **约束条件要和现实对应**：容量约束来自"单条道路每小时最多通过 X 辆车"，必须说明现实依据。
5. **区分有向图和无向图**：交通路网（有方向）和社交关系（通常无方向）处理方式不同，明确声明。

---

### 常见错误

1. **无向图 / 有向图混用**：道路有方向但建成无向图，或社交关系本无方向却建成有向图，导致计算结果错误。
2. **边权单位不一致**：有的边权是距离（km），有的是时间（min），混用后最短路没有意义。
3. **图太乱看不出结论**：50个节点全部显示，颜色没有含义，评委看不出你要表达什么。
4. **只算中心性不回到问题**：算出了介数中心性最高的节点，但没有说"这意味着如果这个节点失效，调度成本会增加多少"。
5. **大图穷举路径**：路径数量指数级增长，暴力穷举不可行，必须用 Dijkstra 等算法。
