# 首页与关卡文案备选（闯关版）

> 用途：闯关训练营页面文案，供前端开发参考  
> 合规原则：轻游戏化感，不幼稚，不重剧情；禁止"代写/保奖/一键论文"等表述  
> 语气：认真但不说教，有挑战感，鼓励学生自主思考

---

## 一、首页一句话定位（3 套备选）

### 定位 A — 强调闯关挑战感

> **7 关，从读题到论文框架，一步一步练清楚**
>
> 每关都要你自己过——AI 只是教练，不替你答题。

- 适合：想完整走一遍建模流程的新手
- 搭配副标题："题目读懂了吗？数据找对了吗？模型选清楚了吗？一关一关来。"
- 搭配行动按钮："开始第 1 关"

---

### 定位 B — 强调思维训练

> **建模不是背公式，是练会想问题**
>
> 7 个关卡，7 个真实建模决策点，AI 帮你想清楚，你来拍板。

- 适合：有一点基础、想提升思维方式的同学
- 搭配副标题："你的思路通了，代码自然跑通；代码通了，论文才有东西写。"
- 搭配行动按钮："挑一道题开始练"

---

### 定位 C — 强调边界清晰（免费试运行版）

> **AI 数学建模学习参谋**
>
> 帮你想清楚方向，剩下的靠你——免费试运行中

- 适合：当前试运行阶段，明确工具定位
- 搭配副标题："不替你写论文。不承诺名次。帮你真正学会建模。"
- 搭配行动按钮："免费体验一关"

## 五、附：禁用表述清单

以下表述在任何页面文案中禁止使用：

| 禁用表述 | 风险类型 | 替代建议 |
|---------|---------|---------|
| 保奖 / 提高获奖率 | 虚假宣传 | "帮你练清楚建模思路" |
| 一键生成论文 | 误导功能 | "搭建论文框架（内容需自己写）" |
| AI 帮你完成建模 | 越位表述 | "AI 引导你完成建模" |
| 降 AIGC 检测率 | 明确违规 | 不能用任何替代表述 |
| 直接提交 / 即用型 | 误导用途 | "仅用于学习练习" |
| 秒出 / 自动完成 | 误导效率 | 不使用效率承诺类表述 |
| 全网最准 / 独家资源 | 夸大内容 | "基于公开数据的教学素材" |
