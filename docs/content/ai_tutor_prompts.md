# AI 问答式学习提示词库

> 用途：学生与 AI 助手（Claude、ChatGPT 等）对话的学习提示词模板  
> 原则：辅助学习，不代写论文；所有提示词均包含"不生成可直接提交内容"的明确约束  
> 适用对象：正在学习某一建模方法的学生，用于理解概念、判断适用性、理解代码和写法

---

## 使用说明

- 将提示词模板中的 `【题目描述】` 替换为你实际的题目文本
- 将 `【你的数据情况】` 替换为你掌握的数据描述
- 每套提示词有 5 个独立提示，**逐步使用**，不要一次全问
- 每次 AI 回答后，用文末的"追问清单"继续深入
- **警惕**：如果 AI 给了你完整的论文段落，这不是学习——那是代写。遇到这种情况请要求它"只解释原理，不写结论段落"

## 套装 1：线性规划 / 整数规划

### 提示词 1 — 概念解释

```
你是一位数学建模学习辅导老师，我是正在学习线性规划的学生。

我的学习目标是理解线性规划的原理，而不是得到答案。请不要帮我写论文段落，也不要给我可以直接提交的最终结论。

请用以下方式解释线性规划：
1. 用一个比喻解释"决策变量、目标函数、约束条件"这三要素是什么
2. 举一个简单的现实例子（3行以内），说明什么叫"把现实问题翻译成数学问题"
3. LP 和 MILP 的区别是什么？什么时候必须用整数变量？

请回答完后问我："你现在手头的题目，你能说出决策变量是什么吗？"
```

---

### 提示词 2 — 适用性判断

```
我正在做一道建模题，请帮我判断线性规划是否适合，但不要替我做判断——请用问题引导我自己做判断。

【题目描述】：（在这里填写你的题目）

请依次问我以下问题，等我回答每一个后再继续：
1. 你想优化的目标是最大化还是最小化？
2. 你的决策变量是什么？它们可以是小数，还是必须是整数？
3. 有哪些限制条件（约束）？这些约束能写成等式或不等式吗？
4. 你有没有多个相互冲突的目标？

根据我的回答，告诉我线性规划是否合适，以及哪个类型（LP/MILP/多目标LP）更匹配——但要解释理由，不要只给结论。
```

---

### 提示词 3 — 最小代码理解

```
我想理解 PuLP 库的基本用法，但我不需要你帮我写完整代码。请展示一个最小例子（3个变量、2个约束），然后逐行解释每一行代码在做什么。

展示完后，不要给我更多代码。请问我：
"你自己的题目里，决策变量有几个？它们的上下限是什么？"

等我回答后，引导我尝试自己写变量定义那一步。
```

---

### 提示词 4 — 检验方法

```
我的线性规划模型已经有一个求解结果了。请告诉我应该怎么检验这个结果是否正确，但不要替我做检验——给我一个"检验清单"，我自己来做。

检验清单应该包括：
1. 怎么检查求解器状态（是否真的有最优解）
2. 怎么逐条验证约束是否满足
3. 怎么做边界情景测试
4. 怎么做灵敏度分析（如果我的关键参数变化 10%，结果怎么变）

请用问句结尾："你检查完约束之后，有没有哪条约束的余量接近于零？那条约束是什么含义？"
```

---

### 提示词 5 — 论文写法引导

```
我需要在论文里写"模型建立"这一节，请告诉我线性规划模型这一节通常应该包含哪些要素，以及它们的顺序。

但请不要帮我写论文内容，只告诉我"结构框架"和"每一部分应该包含什么"。

最后问我："你的约束条件里，每一条背后的现实含义是什么？你能用一句中文说清楚每条约束为什么存在吗？"
```

---

### 追问清单（每次 AI 回答后可选用）

- "你刚才说的约束'Σx ≥ d'，如果这条不满足会发生什么现实情况？"
- "如果我的供给总量小于需求总量，模型会怎样？应该怎么处理？"
- "灵敏度分析说某个约束的影子价格是 5，这是什么意思？"
- "你能不能给我一个'故意犯错'的错误示例，让我找出哪里错了？"
- "多目标优化时，为什么不能直接把两个目标相加？"

## 套装 2：时间序列预测

### 提示词 1 — 概念解释

```
你是一位建模学习辅导老师，我正在学习时间序列预测。请不要帮我写论文，也不要给我可以直接用于提交的结论。

请解释以下概念，每个概念用一个比喻+一句话说明：
1. 平稳性是什么？一个不平稳的时间序列有什么特征？
2. 趋势和周期的区别是什么？
3. ARIMA 的 p、d、q 各代表什么？
4. 为什么时序数据不能随机划分训练集和测试集？

解释完后问我："你的数据有没有明显的趋势？有没有7天或一个月的周期？"
```

---

### 提示词 2 — 适用性判断

```
我有一组时间序列数据，想判断用什么模型预测。请不要替我做判断，用问题引导我。

【我的数据情况】：（在这里描述你有什么数据，时间跨度，大致趋势）

请依次问我：
1. 你的数据按什么时间粒度记录的（每小时、每天、每月）？
2. 数据有没有除了时间以外的其他影响因素（天气、节假日、促销）？
3. 你的目标是"解释哪些因素影响结果"，还是"尽量准确地预测未来值"？
4. 数据量大概多少行？

根据我的回答，告诉我 ARIMA、指数平滑、回归三种方案各自的适用理由，让我自己选。
```

---

### 提示词 3 — 最小代码理解

```
请展示一个最简单的 ARIMA 预测例子：10个数据点，预测未来3步。每行代码旁边加注释解释在做什么。

展示完后，不要给我更多代码。问我：
1. "你知道 ADF 检验是用来做什么的吗？"
2. "如果 ADF 检验的 p 值是 0.3，这说明什么？应该怎么处理？"

等我回答，再继续引导。
```

---

### 提示词 4 — 检验方法

```
请给我一个时间序列预测模型的检验清单，让我自己对照检查——不要替我做。

清单应包括：
1. 如何画残差图并判断是否有规律
2. 如何做滚动验证（rolling CV）而不是单次划分
3. MAE、RMSE、MAPE 三个指标分别适合什么情况
4. 如何判断我的模型是否比"历史均值基准"更好

问我："你的 Baseline 是什么？你算过 Baseline 的 MAE 吗？"
```

---

### 提示词 5 — 论文写法引导

```
请告诉我时间序列预测的论文写法框架，包括：
- "数据分析"节应该包含哪些图表和结论
- "模型建立"节如何解释参数选择过程
- "模型检验"节应该展示哪些误差指标和图表
- 如果预测结果用于优化决策，"模型局限"节应该怎么写误差传递

但请不要帮我写具体内容。问我："你的预测误差是多少？如果这个误差翻倍，你的优化结果会有多大变化？"
```

---

### 追问清单

## 套装 3：回归 / 随机森林

### 提示词 1 — 概念解释

```
我正在学习回归和随机森林，想理解两者的区别和适用场景。请不帮我写论文，只用比喻和简短解释帮我建立直觉。

请解释：
1. 线性回归"假设特征和目标是线性关系"——这个假设什么时候成立，什么时候明显不成立？
2. 随机森林为什么叫"集成模型"？"多棵树投票"的比喻是什么意思？
3. 特征重要性为什么不能说明"因果关系"？用一个例子说明。
4. 过拟合是什么感觉？用一个比喻解释。

解释完问我："你的数据集里，特征和目标变量之间你猜是线性关系还是非线性关系？你有什么依据？"
```

---

### 提示词 2 — 适用性判断

```
我想判断我的题目应该用线性回归还是随机森林。请用问题引导我，不要替我下结论。

【题目描述】：（在这里填写）
【我的特征】：（列出你有哪些特征/输入变量）
【目标变量】：（你想预测的是什么）

请问我：
1. 你的目标变量是连续值（如需求量）还是分类标签（如违约/不违约）？
2. 你的数据量大概多少？特征有多少个？
3. 你更需要"解释哪些因素影响结果"，还是"尽量准确地预测"？
4. 特征里有没有类别型变量（如城市名、工作类型）？

根据我的回答，告诉我哪种模型更合适，并解释理由。不要只给结论。
```

---

### 提示词 3 — 最小代码理解

```
请展示最简单的线性回归+随机森林对比代码（用 sklearn），数据就用 5 行 3 列的假数据。每行代码加注释。

展示完后，问我：
1. "你知道为什么要用 random_state 参数吗？不加会怎样？"
2. "交叉验证和只划分一次训练/测试集有什么区别？"

等我回答，再引导我思考在自己的数据上怎么用。
```

---

### 提示词 4 — 检验方法

```
给我一个回归/随机森林模型的检验清单，不要替我做：

1. 怎么用残差图判断线性假设是否成立
2. 怎么判断是否过拟合（训练误差 vs 测试误差对比）
3. 特征重要性怎么看，什么情况下结果不可信
4. 交叉验证的步骤是什么，时序数据怎么处理

问我："你的模型在训练集上的误差和测试集上的误差分别是多少？差距大吗？"
```

---

### 提示词 5 — 论文写法引导

```
告诉我回归/随机森林在建模论文里"模型建立"节的框架，包括：
- 怎么解释选择这个模型的理由
- 怎么展示特征工程的过程
- 怎么用 Baseline 对比说明进阶模型的价值
- 怎么写特征重要性分析（要注意什么说法是不合适的）

不要写具体段落，只给框架。最后问我："你的 Baseline 是什么模型？它的误差是多少？"
```

## 套装 4：熵权法 / TOPSIS

### 提示词 1 — 概念解释

```
我正在学习熵权法和 TOPSIS，请用直观方式帮我理解核心概念。不要帮我写论文内容。

请解释：
1. 熵权法的"信息熵"是什么？用一个比喻解释为什么差异大的指标权重高。
2. TOPSIS 的"正理想解"和"负理想解"是什么？这个名字怎么理解？
3. "接近度"和"分数"有什么区别？可以说接近度=0.8等于80分吗？
4. 效益型和成本型指标各是什么？请举两个例子。

解释完问我："你的题目里，哪些指标是效益型，哪些是成本型？你确定了吗？"
```

---

### 提示词 2 — 适用性判断

```
我想判断我的评价题目是否适合用熵权法+TOPSIS。请用问题引导我，不要替我下结论。

【题目描述】：（在这里填写）
【评价对象】：（有几个？是什么？）
【指标数量和类型】：（有几个指标？哪些是可量化的？）

请问我：
1. 你的评价目的是"排名"还是"分类"还是"找改进方向"？
2. 指标权重应该反映数据差异（客观），还是人类的价值判断（主观）？
3. 你有没有办法收集到真实的专家打分？
4. 你的指标里有没有所有对象值都相同的指标？

根据我的回答，建议合适的方法组合，并解释为什么。
```

---

```
展示完后问我：

2. "熵权法中 eps=1e-10 是做什么用的？不加会发生什么？"

等我回答再引导。
```

```
3. 怎么用不同方法（如AHP或等权重）做对比验证
4. 如果稳健性检验发现排名变化，怎么在论文里处理

不要替我做检验，给清单后问我："你做了稳健性分析吗？第1名的排名在权重扰动下稳定吗？"
```

## 套装 5：AHP 层次分析法

### 提示词 1 — 概念解释

```
我正在学习 AHP，请帮我建立直觉而不是帮我算答案。

请解释：
1. AHP 适合什么类型的问题？和熵权法最根本的区别是什么？
2. "层次结构"（目标层—准则层—方案层）是什么？用一个日常例子说明。
3. 判断矩阵的 1—9 标度是什么意思？"稍微重要"和"明显重要"有什么区别？
4. 一致性检验（CR < 0.1）是什么意思？如果 CR = 0.2 该怎么办？

解释完问我："你的题目里，你能画出一个3层的层次结构图吗？"
```

---

### 提示词 2 — 适用性判断

```
我想判断我的题目是否适合用 AHP。请用问题引导我。

【题目描述】：（在这里填写）
【指标数量】：（你有几个指标？如何分组？）

请问我：
1. 你的指标有没有天然的层次分组（如先分3个维度，每个维度下有2—3个指标）？
2. 指标权重应该反映哪方面的判断？题目是否给了参考来源？
3. 你能接受主观打分带来的"人为因素"影响吗？如果不能，有没有备选方法？
4. 你有多少个指标？超过9个怎么办？

根据我的回答，告诉我 AHP 是否合适，并建议怎么用。
```

---

### 提示词 3 — 最小代码理解

```
请展示一个最简单的 AHP 计算例子：3个指标，判断矩阵已知。用 numpy 计算权重和 CR，每步加注释。

展示后问我：
1. "判断矩阵的'互反性'是什么要求？如果 A 对 B 打分 3，B 对 A 应该打多少？"

等我回答，再引导我用自己的判断矩阵试试。
```

### 提示词 4 — 检验方法

```
2. 怎么验证权重对结果排名的影响（权重敏感性）
3. 怎么和熵权法结果对比，验证主客观权重的差异是否合理
4. 如果两个方法给出的排名不同，论文里怎么写

```
