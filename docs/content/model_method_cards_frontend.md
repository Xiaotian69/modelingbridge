# 模型方法卡（前端展示版）

> 用途：第 4 关"模型选择"界面的参考卡片，供学生在选模型时快速查阅  
> 规格：每卡正文 ≤220字；noviceQuestions ≥3条；字段定义见下方  
> 合规说明：卡片只提供选择框架，不替学生做最终判断；无保奖承诺

---

## 字段说明

| 字段 | 说明 |
|------|------|
| `modelId` | 唯一标识，用于前端 key |
| `name` | 显示名称 |
| `fitWhen` | 一句话：什么情况下适合（≤40字） |
| `requiredData` | 需要哪类数据（≤40字） |
| `output` | 输出什么（≤30字） |
| `commonMisuse` | 最常见的1-2个误用（每条 ≤30字） |
| `validation` | 怎么验证结果正确（≤50字） |
| `noviceQuestions` | 学生用来自检的问题（≥3条，每条 ≤40字） |
| `paperExpressionTip` | 论文里如何简洁描述本模型（≤30字） |

## 卡 1：线性规划 / 整数规划

**modelId**：`lp_milp`  
**name**：线性规划 / 整数规划（LP / MILP）  
**家族**：优化 | **层级**：入门—进阶

**fitWhen**  
目标函数和所有约束都是线性的，需要在约束下最大化或最小化某个目标。

**requiredData**  
目标函数系数、约束右端项；整数规划需指定哪些变量必须取整。

**output**  
最优决策变量值、目标函数最优值、求解状态（Optimal/Infeasible）。

**commonMisuse**  
1. 漏掉非负约束，导致决策变量出现负值（如负调度量）。  
2. 目标函数含乘积或平方项，误用LP建模。

**validation**  
把结果代回所有约束逐条验证是否满足；与不调度的Baseline对比目标函数值。

**noviceQuestions**  
1. 你能写出目标函数的数学表达式吗？写不出来说明建模还没完成。  
2. 你的决策变量是连续实数还是必须整数？整数变量要用MILP。  
3. 目标函数和约束里有变量的乘积或平方吗？有则不是线性规划。  
4. 总供给量是否≥总需求量？不满足则LP无可行解，需先处理这个矛盾。

**paperExpressionTip**  
先写决策变量定义，再写目标函数公式，再逐条写约束，最后说明求解状态。

## 卡 2：时间序列预测（ARIMA / 指数平滑）

**modelId**：`arima`  
**name**：时间序列预测（ARIMA / 指数平滑）  
**家族**：预测 | **层级**：入门

**fitWhen**  
数据是按时间排列的序列，只用历史值预测未来值，不需要引入外部特征。

**requiredData**  
等间隔时序数据（最少50个观测点），时间戳必须连续无跳空。

**output**  
未来N个时间点的预测值；可选预测区间；MAE/RMSE评价指标。

**commonMisuse**  
1. 随机分割训练/测试集——时序数据必须按时间顺序划分，不能shuffle。  
2. 不做ADF平稳性检验就用ARIMA。

**validation**  
在时间顺序的测试集上计算MAE/RMSE，与历史均值Baseline对比；画真实值vs预测值折线图目视检查。

**noviceQuestions**  
1. 你的数据是等间隔时间序列吗？有没有跳空的时间点？  
2. 你有外部特征（天气、节假日）需要利用吗？有的话ARIMA不适合。  
3. 你做ADF检验确认序列平稳了吗？  
4. 你的测试集是按时间顺序划出的最后一段吗？如果随机划分请改正。

**paperExpressionTip**  
说明p/d/q参数确定方法（ACF/PACF图或AIC准则），给出测试集MAE并与Baseline对比。

## 卡 3：回归分析 / 随机森林

**modelId**：`regression_rf`  
**name**：回归分析 / 随机森林  
**家族**：预测 | **层级**：入门（回归）/ 进阶（随机森林）

**fitWhen**  
有多个解释变量（特征）想预测连续目标，或样本量充足（>100条）且特征间关系复杂。

**requiredData**  
特征矩阵（数值型或编码后的类别特征）+ 目标变量（连续数值）；样本量线性回归≥30条，随机森林≥100条。

**output**  
预测值；线性回归的系数+p值；随机森林的特征重要性排名；MSE/MAE/R²。

**commonMisuse**  
1. 时序特征随机划分数据集，造成数据泄露（用未来数据预测过去）。  
2. 线性回归中不检查多重共线性（VIF），系数不稳定。

**validation**  
对比训练集和测试集上的MAE/R²，差距大说明过拟合；残差图应随机分布无系统偏差。

**noviceQuestions**  
1. 你的目标变量是连续数值还是类别？类别要用分类模型，不是回归。  
2. 你的特征里有时间维度吗（时序相关）？需要考虑滞后特征，避免数据泄露。  
3. 你关心"预测精度高"还是"可解释性强"？两者对应不同模型选择。  
4. 特征之间有没有高度相关的？相关特征放线性回归里会出问题。

**paperExpressionTip**  
说明特征选取和工程方法，给出交叉验证策略，测试集MAE/R²配预测vs真实值折线图。

## 卡 4：熵权法 + TOPSIS

**modelId**：`entropy_topsis`  
**name**：熵权法 + TOPSIS  
**家族**：综合评价 | **层级**：入门

**fitWhen**  
有多个评价对象（≥3个）、多个评价指标，需要综合排名，且希望权重由数据客观决定。

**requiredData**  
评价矩阵：行=评价对象，列=评价指标（5-10个），每个指标需标注效益型或成本型。

**output**  
权重向量w（总和=1）、每个对象的相对接近度C（0-1之间）、排名结果。

**commonMisuse**  
1. 效益型/成本型判断错误，排名结果完全反转（"等待时间越短越好"是成本型）。  
2. 某格数据为0时取log，报错——需加epsilon（约1e-9）处理。

**validation**  
权重总和验证=1；手动计算1个对象的D+和D-，与代码输出对比；做±20%权重扰动的稳健性检验。

**noviceQuestions**  
1. 你能为每个指标判断效益型/成本型吗？有没有不确定怎么判断的指标？  
2. 你的评价对象有多少个？少于3个时熵权法权重可能失真。  
3. 有没有某个指标所有对象得分完全相同？（该指标权重会变成0，需要处理）  
4. 你做稳健性检验了吗？没做就不知道排名是否稳定。

**paperExpressionTip**  
说明指标类型标注和标准化公式（效益/成本型分别列），给出CR值（若与AHP结合），配稳健性分析。

## 卡 5：层次分析法（AHP）

**modelId**：`ahp`  
**name**：层次分析法（AHP）  
**家族**：综合评价 | **层级**：入门

**fitWhen**  
需要引入专家判断确定权重，题目允许或要求主观权重，有两两比较数据支撑。

**requiredData**  
专家两两比较矩阵（1-9比例标度），矩阵大小=指标数×指标数；无真实专家意见时须在论文中声明。

**output**  
各指标相对权重向量（总和=1）；一致性比例CR（必须<0.1）。

**commonMisuse**  
1. CR≥0.1不修正，直接用结论，一致性不达标导致权重不可信。  
2. 无来源的比较矩阵——自己随意填写，论文缺乏依据。

**validation**  
CR = CI/RI < 0.1；权重总和=1；对比权重与直觉判断是否一致（A比B重要3倍，矩阵里是否填了3？）。

**noviceQuestions**  
1. 你的两两比较矩阵来源是什么？真实专家/文献参考/作者判断——论文里要说清楚。  
2. 你的CR值是多少？如果≥0.1，你打算怎么修正比较矩阵？  
3. 你能向别人解释"为什么指标A比指标B重要3倍"吗？这个解释要写进论文。  
4. 你和熵权法都做了吗？两者权重差距大说明主客观判断不一致，需要讨论。

**paperExpressionTip**  
给出比较矩阵、权重向量和CR值，说明矩阵来源，说明权重与业务理解是否一致。

## 卡 6：聚类分析（K-Means / 层次聚类）

**modelId**：`clustering`  
**name**：聚类分析（K-Means / 层次聚类）  
**家族**：规律发现 | **层级**：入门

**fitWhen**  
有一批对象需要按相似性自动分组，不需要提前知道"正确分法"（无监督学习）。

**requiredData**  
特征矩阵（行=样本，列=数值型特征，需标准化）；样本量K-Means≥20条，推荐100+。

**output**  
每个样本的类别标签（0/1/2...）、各簇中心特征均值；轮廓系数/Inertia评价指标。

**commonMisuse**  
1. 不标准化就做聚类——量纲大的特征主导结果，量纲小的特征失效。  
2. K值随意选——没用肘部法则或轮廓系数，论文无法说服评委。

**validation**  
肘部法则找K（K vs Inertia曲线拐点）；轮廓系数取不同K中最大的；每簇箱线图验证特征有区分性。

**noviceQuestions**  
1. 你的特征做聚类前标准化了吗？没有的话量纲大的特征会主导结果。  
2. 你用什么方法选择K值？随意选的K在论文里无法说服评委。  
3. 你能用几句话描述每个簇的业务特征吗？说不出来说明聚类结果没有实际意义。  
4. 你的聚类结果每个簇有多少样本？某个簇只有1-2个样本说明K选大了。

**paperExpressionTip**  
说明K值确定方法（肘部法则或轮廓系数），说明每类的业务含义，配雷达图或热力图展示各簇特征差异。

## 卡 7：微分方程模型（ODE）

**modelId**：`ode`  
**name**：微分方程模型（ODE / SIR等）  
**家族**：动态系统 | **层级**：进阶

**fitWhen**  
问题涉及随时间变化的连续系统，变化规律可用增长率/衰减率/传播速率等描述。

**requiredData**  
初始条件（t=0时刻的系统状态）；参数估计用的真实观测数据；时间步长。

**output**  
系统状态随时间的演化曲线（各状态变量的时间序列）；估计的模型参数；预测值。

**commonMisuse**  
1. 参数凭空猜测——β=0.3、γ=0.1无任何来源，结论不可信。  
2. 步长太大导致数值不稳定（建议先用scipy.integrate.solve_ivp）。

**validation**  
参数拟合到训练数据后在测试数据上评估MAE；画真实数据vs模型拟合曲线目视吻合；做参数灵敏度分析（参数±10%时峰值变化多少）。

**noviceQuestions**  
1. 你能用语言描述你的系统"状态变量有哪些、状态之间如何转化"吗？说不清楚说明模型结构还没想好。  
2. 你的模型参数从哪里来——文献、数据拟合，还是你猜的？猜的参数论文里怎么说明？  
3. 你的初始条件从哪里来，是真实数据还是假设？  
4. 你的模型最核心的假设是什么（如接触率均匀、忽略年龄差异）？这些假设合理吗？

**paperExpressionTip**  
写出微分方程组（含每个方程的含义解释），说明参数估计方法，给出参数值及数据来源。

## 卡 8：网络流 / 图论模型

**modelId**：`network_flow`  
**name**：网络流 / 图论模型  
**家族**：网络优化 | **层级**：进阶

**fitWhen**  
问题可以表示为节点和边的网络，需要做最短路、最大流、路径规划等操作。

**requiredData**  
节点列表（含属性：坐标/容量/需求）、边列表（含权重：距离/时间/成本）。

**output**  
最短路径（节点序列+路径长度）；最大流值；最优路径方案（VRP/TSP类）。

**commonMisuse**  
1. 把有向图当无向图——道路有方向（单行道）时不能用无向图。  
2. TSP/VRP超过15个节点却暴力枚举，计算不可行。

**validation**  
用networkx可视化验证节点和边正确；手动计算1-2条路径与算法对比；最大流验证源点流出量=汇点流入量（守恒）。

**noviceQuestions**  
1. 你的问题能画成节点-边的网络图吗？画不出来可能不适合用图论。  
2. 你的边是有方向的还是无方向的？（单行道/双向道路/流量方向）  
3. 你需要的是"从A到B最短路"还是"访问所有节点的最优路线"？两者算法完全不同。  
4. 你的边权代表什么（时间/距离/成本）？论文里说明了边权来源和单位吗？

**paperExpressionTip**  
说明建图方式（如何从题目数据建出节点和边），说明所用图算法及理由，给出路径可视化图。

## 附：模型选择快速决策树

```
你的题目要求什么？
│
├─ 预测一个未来数值
│   ├─ 只有时间序列，无外部特征 → 时间序列模型（ARIMA/指数平滑）[卡2]
│   └─ 有多个特征（天气/节假日/属性）→ 回归 / 随机森林 [卡3]
│
├─ 对多个对象排名/打分
│   ├─ 权重由数据客观决定 → 熵权法 + TOPSIS [卡4]
│   └─ 权重引入专家判断 → AHP（或AHP+TOPSIS）[卡5]
│
├─ 在约束下最大化/最小化目标
│   ├─ 目标和约束都是线性 → 线性规划（LP/MILP）[卡1]
│   └─ 有非线性项 → 非线性规划（NLP，本版暂不展开）
│
├─ 把一批对象自动分组
│   └─ 聚类分析（K-Means/层次聚类）[卡6]
│
├─ 描述随时间变化的连续系统
│   └─ 微分方程（ODE/SIR等）[卡7]
│
└─ 在网络/地图上做路径/流量/覆盖分析
    └─ 图论 / 网络流（Dijkstra/最大流/VRP）[卡8]
```

> 决策树只是辅助，最终选择必须由学生根据题目条件和数据情况自己判断。
