# 闯关训练副本内容矩阵（3 案例 × 7 关）

> 用途：前端工程接入素材，Codex 直接从本文件提取各字段填入 `cases/*.json`  
> 字段规格：taskBrief ≤80字 · studentPrompt ≤120字 · coachHint 每条 ≤80字 · 其余字段如标注  
> 合规基线：产物示例只给结构短句；不写可直接提交的论文段落；无保奖/代写承诺

## 案例一：校园共享单车需求预测与调度

**caseId**：`bike_demand`  
**难度**：入门  
**核心模型**：时间序列预测 + 线性规划

---

### 关 1｜读题破冰

**taskBrief**（≤80字）  
用自己的话说清楚这道题"给了什么、要算什么、最后交什么"，并列出至少3个读题后的疑问。

**studentPrompt**（≤120字）  
请不引用原题原话，用一句话写出题目摘要；圈出你不确定含义的词；判断这道题是预测题、优化题，还是两者都有，并说明理由。

**coachHints**（每条 ≤80字）  
1. 你说这道题是"预测+调度"，这两步的顺序是什么？预测结果如何传给调度模型？  
2. 题目里有没有说清楚"调度成本"如何定义？假设不同会怎么影响结论？  
3. 如果只做预测不做调度，这道题会丢掉哪些得分点？

**commonMistakes**  
1. 把题目当纯预测题，忽略了调度方案的输出要求。  
2. 不区分区域级和站点级数据粒度，导致后续模型维度设置错误。

**outputExample**（结构短句，非完整段落）  
```
题目摘要：输入=历史订单（时间/区域/量）+天气+节假日；
小问A输出=7天×各区域×各时段需求预测矩阵；
小问B输出=各区域调入/调出量+总成本+KPI对比；
疑问清单：①调度成本定义 ②数据粒度 ③是否允许多次调度
```

**mustDoByStudent**：用自己的语言写题目摘要（不能复制原题）；列出至少3条具体疑问。

**complianceNote**：AI只帮检查理解，不给"正确答案"或"标准解读"。

---

### 关 2｜拆解任务

**taskBrief**  
把题目拆成至少2个有输入/输出的子问题，说清楚子问题之间的依赖关系和接口。

**studentPrompt**  
请列出你的子问题拆解表（每个子问题一行：输入 → 名称 → 输出）；标出哪个子问题必须先完成；对每个子问题给出难度评估（简单/中等/挑战）并说明理由。

**coachHints**  
1. 小问A的输出是矩阵——这个矩阵的行、列、值分别代表什么？说清楚维度才能往下走。  
2. 预测有误差，误差会怎么传递到调度方案？这个问题在论文里要讨论。  
3. 调度子问题有哪些约束？约束没列全是建模失分的常见原因，先列约束清单。

**commonMistakes**  
1. 小问A与B的接口没有定义清楚，代码阶段两模块数据格式不兼容。  
2. 把"讨论"子问题当附录而非独立子问题，导致论文结构松散。

**outputExample**  
```
子问题A：需求预测
  输入：历史订单矩阵 + 天气特征 + 节假日标记
  输出：future_demand[7天 × n_zones × 24h]（含误差范围）
  难度：中等；理由：需要特征工程和交叉验证
子问题B：调度优化
  输入：future_demand矩阵 + 车辆总数约束 + 成本参数
  输出：dispatch_matrix[n_zones × n_zones]（调入/调出量）
  难度：中等；理由：LP建模需手动定义约束
```

**mustDoByStudent**：子问题输入/输出必须具体，不能只写"数据"；依赖关系必须说明。

**complianceNote**：拆解框架是学习工具，不能直接用AI给出的拆法替代自己的判断。

---

### 关 3｜数据侦查

**taskBrief**  
搞清楚哪些数据已有、哪些需要获取、哪些需要假设，并对手头数据做至少3项质量检查。

**studentPrompt**  
请填写三栏数据清单（已有/待获取/需假设），对每类数据写一句描述（来源·规模·关键字段）；标出至少1个数据风险点。

**coachHints**  
1. 你认为"理所当然有"但题目没明确给出的数据，属于哪一栏？先把它移到"需假设"那列。  
2. 时序数据必须检查：时间戳是否连续？有没有跳空？你检查了吗？  
3. 哪个字段含义你还没完全确认？不清楚就先不要用它建模。

**commonMistakes**  
1. 数据栏只写字段名，没有说明含义，导致后续建模时字段用错方向。  
2. 外部数据来源只写"网上找的"，论文无法引用。

**outputExample**  
```
已有（题目附件）：订单表[12万行×8列；关键字段：时间戳/区域ID/需求量]
待获取（外部）：天气数据[来源：某气象公开API；字段：温度/降水/风速]
需假设：节假日标记[来源：国家法定假日表；假设工作日/非工作日二分]
数据风险：区域ID定义不明——题目未说明区域颗粒度，若粒度理解错导致维度不匹配
```

**mustDoByStudent**：三栏清单每栏至少1条带说明的条目；必须亲自做质量检查并记录结果。

**complianceNote**：外部数据必须注明来源；假设数据须在报告中标注"假设数据，仅用于方法验证"。

### 关 4｜模型选择

**taskBrief**  
为需求预测子问题和调度子问题各列出至少2个候选模型，做对比表，给出最终选择和理由。

**studentPrompt**  
请列出候选模型清单（每个候选含适用前提）；从"数据需求/输出形式/解释难度/实现难度"四维度做对比表；用3句以上说明你的最终选择，并列出所选模型的至少2个前提假设。

**coachHints**  
1. 预测模型：你只有时间序列特征，还是有天气等外部特征？两种情况对应不同的模型范围。  
2. 调度模型：你能把优化目标写成数学表达式吗？写不出来说明建模还没想清楚。  
3. 如果主选模型实现不出来，你的备选是什么？备选和主选的差距在哪里？

**commonMistakes**  
1. 选ARIMA但数据有天气特征——ARIMA不能利用外部特征，需改用回归模型。  
2. LP约束漏掉非负限制，导致输出出现负值调度量。

**outputExample**  
```
预测候选：ARIMA（纯时序，无外部特征）vs. 随机森林回归（含天气特征）
最终选择：随机森林——原因：题目附件含天气数据，利用特征可提升精度；
  代价：可解释性弱于线性模型，需补充特征重要性分析
模型假设：①各区域需求相互独立 ②天气与需求线性相关（近似）
```

**mustDoByStudent**：选择理由必须用自己的语言写，不少于3句；对比表必须由学生自己填写。

**complianceNote**：AI不能说"你应该用XX模型"；模型选择是学生的学术判断。

---

### 关 5｜代码起步

**taskBrief**  
搭建代码框架，跑通至少一个子问题的基础版本，并对输出结果做常识验证。

**studentPrompt**  
请完成：数据读入并打印统计摘要（行/列/缺失值/均值）；跑通所选预测模型的最简版本；对输出结果做常识判断并记录依据（不能只写"结果正确"）。

**coachHints**  
1. 数据读入后第一件事打印什么？先看数据长什么样，再决定怎么清洗。  
2. 你预测出来的需求量，量级是否合理？一个停车区域一天需求几百辆？几千辆？  
3. 代码现在哪个地方最脆弱——换一组数据后最容易出错的是哪里？

**commonMistakes**  
1. 直接在全部数据上拟合，没有留出测试集，训练集指标好但泛化性未知。  
2. 预测值全为负或全为0——没有检查，论文里直接用了错误结果。

**outputExample**  
```
数据读入：df.shape=(120000, 8)；缺失值：weather列3.2%；时间范围：2023-01-01~2024-12-31
基础模型跑通：随机森林 n_estimators=100，测试集MAE=12.3辆/小时
常识验证：高峰时段预测均值=87辆，低峰时段=23辆，与历史统计吻合，量级合理
```

**mustDoByStudent**：必须亲自跑代码并截图/记录；合理性判断必须写出依据，不能默认AI生成代码正确。

**complianceNote**：代码框架是起点，所有函数细节必须学生自己实现；AI不提供完整可运行代码。

### 关 6｜图表表达

**taskBrief**  
为每个核心结论做至少1张配套图，每张图有完整标注，并用一句话说清楚"这张图回答了哪个问题"。

**studentPrompt**  
请先列图表计划（每张图服务哪个子问题、结论是什么），再完善图表标注，最后对照图表自查清单检查每张图。

**coachHints**  
1. 这张图想让读者看到什么结论？只看图不看文字，能看出来吗？  
2. 你的预测折线图里，真实值和预测值用同一颜色了吗？图例说清楚了吗？  
3. 如果只保留两张最重要的图，你会选哪两张？理由是什么？

**commonMistakes**  
1. 折线图有5条线但图例只写颜色名，读者不知道哪条线代表什么。  
2. 优化结果只有一个数字，没有对比图（优化前 vs 优化后），结论缺少说服力。

**outputExample**  
```
图1：真实需求 vs 预测需求折线图（x=时间，y=需求量/辆，蓝=真实，红=预测，阴影=95%CI）
  图注：图1表明随机森林对高峰时段预测MAE=12.3辆，比历史均值Baseline低34%
图2：各区域优化后调度量热力图（x=来源区域，y=目标区域，颜色=调度量）
  图注：图2表明优化方案主要从低峰区向高峰区调车，总调度量=1240辆，成本比基线低18%
```

**mustDoByStudent**：图表必须基于真实计算结果；如用假设数据需在图注标明。

**complianceNote**：AI不能替学生设计图表或生成论文所需图片。

### 关 7｜论文框架

**taskBrief**  
搭建论文目录（章节名要具体），为每章写1句说明，填写假设表，完成论文自查清单。

**studentPrompt**  
请写出这篇论文的完整目录（章节名具体，不能用"第三章 建模"之类模板标题）；为每章写1句"这章要说什么、用什么支撑"；列出至少3条建模假设（含至少1条隐含假设）。

**coachHints**  
1. 你的摘要有没有写出定量结论？"预测MAE=12.3"和"效果更好"哪个更有说服力？  
2. 假设列表里有没有默默用了但没写出来的前提，比如"数据没有系统误差"？  
3. 你的参考文献有几条？每条你真的读过吗？只列真实阅读过的。

**commonMistakes**  
1. 目录章节名用模板（"第三章 建模"），没有写出具体模型名称。  
2. 假设列表只有1-2条，缺少对数据质量和模型适用范围的隐含假设。

**outputExample**  
```
目录骨架（示例结构，学生需用自己题目填写）：
  摘要（含MAE/成本对比数字）
  1 问题重述与假设
    1.1 问题背景与目标（用自己语言，非复制原题）
    1.2 建模假设（至少3条，含隐含假设）
  2 数据说明与预处理
  3 共享单车需求预测模型
    3.1 特征工程与随机森林模型
    3.2 模型验证（测试集MAE与Baseline对比）
  4 区域调度优化模型（线性规划）
    4.1 决策变量与约束定义
    4.2 求解结果与灵敏度分析
  5 结论与讨论
  参考文献（仅列真实阅读过的文献）
```

**mustDoByStudent**：论文段落必须自己写，不能直接粘贴AI输出；文献只列真实阅读过的。

**complianceNote**：论文框架是学习规划工具，不是可直接提交的论文；参考文献不得虚构。

## 案例二：多维指标综合评价

**caseId**：`evaluation_topsis`  
**难度**：入门  
**核心模型**：熵权法 + TOPSIS（可选AHP对比）

---

### 关 1｜读题破冰

**taskBrief**  
说清楚题目"要评价的是谁、评价依据是什么、最后要给出什么结论"，并列出至少3个读题疑问。

**studentPrompt**  
请用自己的语言写一句话摘要（不引用原题）；圈出"评价对象""评价指标""指标权重来源"三个关键点；列出你现在最不确定的3个问题。

**coachHints**  
1. 你说要"综合评价"——评价对象是什么，有几个？评价指标有几条，类型如何？  
2. 题目有没有说权重由谁决定——数据说了算还是专家说了算？这两种路线方法不同。  
3. 最终输出是"排名"还是"分数"？两者对评委的说服力不同，你怎么看？

**commonMistakes**  
1. 把"综合评价"理解成"加权平均"，没有意识到需要先定义指标类型（效益/成本）。  
2. 读题时忽略了"附件中指标权重已给出"或"需要自己确定权重"的关键信息。

**outputExample**  
```
题目摘要：输入=n个评价对象×m个指标的数据矩阵；
  小问A输出=各指标权重（需说明方法：客观/主观）；
  小问B输出=综合评分排名列表；
疑问：①是否有指标需要正向化 ②评价对象数量 ③时间数据如何处理（若有）
```

**mustDoByStudent**：自己判断指标类型（效益型/成本型）；用自己语言写摘要。

**complianceNote**：权重是学生的学术判断，AI不能替学生决定用哪种方法。

---

### 关 2｜拆解任务

**taskBrief**  
把评价任务拆成"数据预处理→权重确定→综合评分→验证"4个步骤，写清楚每步的输入/输出。

**studentPrompt**  
请画出4步流程图（每步写输入/输出和估计难度）；说明如果题目要求同时用客观法和主观法，两者的权重如何融合。

**coachHints**  
1. 你的第一步是什么——直接建模还是先处理指标量纲？量纲不统一，熵权法会出错。  
2. AHP和熵权法的输出格式相同（都是权重向量），但输入来源不同——你清楚吗？  
3. 如果AHP和熵权法给出的权重差距很大，你打算在论文里怎么讨论？

**commonMistakes**  
1. 跳过标准化直接计算熵——量纲不同时（如温度℃ vs 费用元）结果失真。  
2. 把AHP的比较矩阵随意填写，没有说明依据，论文缺乏说服力。

**outputExample**  
```
步骤A：数据预处理
  输入：原始数据矩阵[n×m]；操作：效益型/成本型标注+标准化
  输出：标准化矩阵[n×m]（值域[0,1]）
步骤B：权重确定（熵权法）
  输入：标准化矩阵；输出：权重向量w[m]（总和=1）
步骤C：TOPSIS综合评分
  输入：标准化矩阵+权重向量；输出：各对象相对接近度C[n]
步骤D：排名与验证
  输入：C值；输出：排名列表+稳健性检验结果
```

**mustDoByStudent**：步骤拆解必须自己完成；输入/输出不能只写"数据"。

**complianceNote**：拆解框架是学习辅助，不能直接用作论文正文。

---

### 关 3｜数据侦查

**taskBrief**  
检查评价矩阵的完整性：对象数、指标数、效益/成本类型、缺失值、量纲一致性。

**studentPrompt**  
请列出数据清单（3栏：已有/待获取/需假设）；对矩阵做4项检查并记录结果（缺失值/量纲/效益-成本类型/对象数是否≥3）；标出最可能出问题的字段。

**coachHints**  
1. 你的指标里，有没有"越小越好"的？成本型指标标错方向，排名会完全反转。  
2. 所有对象某个指标值相同——这个指标在熵权法里权重会变成0，你知道怎么处理吗？  
3. 数据来源是题目附件还是外部收集？外部来源在论文里怎么引用？

**commonMistakes**  
1. 效益型/成本型判断错误——"等待时间越短越好"是成本型，误填效益型导致排名反转。  
2. 有一个指标所有对象得分完全相同，没有处理，导致熵权法报错（log0）。

**outputExample**  
```
评价矩阵：8个城市 × 6个指标 [来源：题目附件，无缺失值]
指标类型：GDP增速(效益)·PM2.5(成本)·绿化率(效益)·人均收入(效益)·交通拥堵(成本)·医疗床位(效益)
数据风险：PM2.5单位为μg/m³，GDP单位为亿元——量纲差异极大，标准化前必须处理
```

**mustDoByStudent**：效益/成本判断必须自己做，逐指标标注；质量检查必须记录"结果是否正常"。

**complianceNote**：不得虚构数据；来源不可追溯的数据不能进论文。

---

### 关 4｜模型选择

**taskBrief**  
为权重确定和综合评分各列至少2个候选方法，做对比，给出选择理由，列出前提假设。

**studentPrompt**  
权重候选：熵权法 vs AHP（或其他），从"数据需求/主客观/前提假设/局限"4维对比；评分候选：TOPSIS vs 线性加权，给出选择理由（不少于3句话）。

**coachHints**  
1. 熵权法要求评价对象之间有差异——如果所有对象指标都差不多，权重会接近均匀分布，还有意义吗？  
2. TOPSIS的相对接近度C=0.82不是"82分"——你论文里打算怎么描述这个数？  
3. 如果题目要求"既有客观数据又有专家意见"，你怎么把两种权重融合起来？

**commonMistakes**  
1. 把TOPSIS的接近度C当成百分制分数，在论文里写"该城市得了82分"——描述错误。

### 关 1｜读题破冰

**taskBrief**  
说清楚"优化什么目标、受什么约束、决策变量是什么"，列出至少3个读题疑问。
