# 界面微文案 v2（闯关版）

> 版本：v2（2026-05-25）  
> 用途：前端 UI 各场景的短文案，供 Codex 按场景类型直接选用  
> 语气：认真但不说教，有挑战感，不夸张，不承诺结果  
> 合规底线：禁用"保奖/一键论文/降AIGC/直接提交/代写"等表述

---

## 一、继续按钮（10 条）

> 用于"已开始未完成的关卡"的主操作按钮；语气：鼓励继续，不施压

| 编号 | 文案 | 适用场景 |
|------|------|---------|
| C-01 | 继续这一关 | 通用"继续"按钮 |
| C-02 | 接着做 | 简短版，适合空间紧凑的按钮 |
| C-03 | 继续第 {N} 关 | 带关卡编号的继续，适合关卡列表 |
| C-04 | 还差一点，继续 | 进度接近完成时（≥60% 通关条件已勾选）|
| C-05 | 把这关做完 | 进度偏低时的鼓励语 |
| C-06 | 回到上次进度 | 用户离开后重新进入 |
| C-07 | 继续思考 | 答案框已有内容但还未通关 |
| C-08 | 这关还没完，继续 | 用户试图跳关时的提醒性按钮 |
| C-09 | 先完成这关再往下 | 下一关入口锁定时的解释文案 |
| C-10 | 写多一点，再试试通关 | 答案不足20字时的引导文案 |

## 附：禁用表述清单（v2 更新）

> 以下表述在所有界面文案中禁止使用

| 禁用表述 | 风险类型 | 替代建议 |
|---------|---------|---------|
| 保奖 / 提高获奖率 | 虚假宣传 | "帮你练清楚建模思路" |
| 一键生成论文 | 误导功能 | "搭建论文框架（内容需自己写）" |
| AI 帮你完成建模 | 越位表述 | "AI 引导你完成建模" |
| 降 AIGC 检测率 | 明确违规 | 不能用任何替代表述 |
| 直接提交 / 即用型 | 误导用途 | "仅用于学习练习" |
| 秒出 / 自动完成 | 误导效率 | 不使用效率承诺类表述 |
| 全网最准 / 独家资源 | 夸大内容 | "基于公开数据的教学素材" |
| 代写 / 代做 | 违规服务 | 不存在任何形式的替代表述 |
