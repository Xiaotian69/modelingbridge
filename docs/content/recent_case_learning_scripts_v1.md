## 2023C Wordle

### 学习定位

这是最适合小白入门的美赛数据题之一。它没有复杂物理背景，核心是把“一个单词为什么难猜”转成可计算特征，再用模型解释和预测。

| 维度 | 内容 |
| --- | --- |
| 题型 | 特征工程 + 预测 + 分类 + 写给编辑的短文 |
| 核心模型 | 回归/随机森林、时间序列、聚类 |
| 适合课程 | 课程15 特征工程、课程18 回归、课程19 时间序列、课程11 写作 |
| 本地附件 | `2023_MCM_ICM_Problems/Problem_C_Data_Wordle.xlsx` |

### 小白版任务

给定 2022 年每日 Wordle 结果，完成三件事：

1. 解释每天报告人数为什么变化，并预测某一天的报告人数区间。
2. 给定一个未来单词，预测 1 到 X 次猜中的比例分布。
3. 给单词难度分层，并说明哪些单词特征让它更难。

### 数据字段

本地数据表共有 360 行、13 列。原始表头有合并/空列，接入前应重命名为：

| 字段 | 含义 | 学习用途 |
| --- | --- | --- |
| `date` | 日期 | 时间序列划分 |
| `contest_number` | 题号 | 趋势/顺序特征 |
| `word` | 当日单词 | 生成字母特征 |
| `reported_results` | 报告人数 | 预测目标 1 |
| `hard_mode_count` | Hard Mode 人数 | Hard Mode 比例分析 |
| `try_1` 至 `try_6` | 1-6 次猜中的比例 | 分布预测 |
| `try_x` | 未猜中比例 | 难度指标 |

建议派生特征：

- 是否有重复字母。
- 不同字母个数。
- 元音个数。
- 首字母/末字母。
- 字母频率总分。
- 是否罕见字母。
- 单词常见度或词频。
- 星期、月份、距离发布时间的天数。

### 建模学习脚本

| 学习步 | 学生要做什么 | AI 教练只做什么 |
| --- | --- | --- |
| 读题 | 写清楚 NYT 要你回答哪些问题 | 追问“预测对象”和“输出格式” |
| 拆题 | 拆成报告人数预测、分布预测、难度分类、编辑信 | 检查是否漏掉不确定性 |
| 数据 | 清洗表头，检查比例是否约等于 100 | 提醒处理四舍五入误差 |
| 特征 | 为每个单词设计 6-10 个可解释特征 | 提醒特征必须能从单词本身得到 |
| 模型 | 先做 baseline，再做回归/随机森林 | 帮学生比较模型，而不替学生选最终模型 |
| 检验 | 用时间后段做测试集，给 MAE/RMSE | 提醒不能随机切分时序目标 |
| 论文 | 写给编辑的 1-2 页建议信 | 检查是否有数字结论和局限 |

### 编程训练

最低可运行版本：

1. 读取 Excel，重命名字段。
2. 计算 Hard Mode 比例和平均猜测次数。
3. 从 `word` 派生字母特征。
4. 用历史均值或线性回归预测 `reported_results`。
5. 用随机森林预测 `try_1` 到 `try_x` 分布。
6. 用平均猜测次数或聚类结果定义难度等级。

必须输出：

- 字段说明表。
- 单词特征表。
- 报告人数预测误差。
- EERIE 的分布预测示意。
- 难度分层和代表单词。

### 论文表达训练

小白论文结构：

1. 问题重述：我们要解释参与度、预测得分分布、分类难度。
2. 数据说明：数据来自每日 Wordle 统计，存在比例四舍五入误差。
3. 特征工程：解释每个单词特征为什么可能影响难度。
4. 模型一：报告人数预测。
5. 模型二：得分分布预测。
6. 模型三：难度分类。
7. 给编辑的建议信。

### 获奖论文路线参考

只做教学拆解，不复制正文。

| 论文 | 模型路线 | 可学点 |
| --- | --- | --- |
| `2300348` | GRU 预测报告人数；回归分析单词属性；网格搜索随机森林预测得分分布；K-Means++ 分难度 | 任务拆分完整，适合学习“预测 + 分类 + 稳健性” |
| `2301192` | SIRS/Prophet 解释热度变化；多元线性回归分析 Hard Mode；BP 神经网络预测分布；K-Means++ 分类 | 把参与人数类比传播模型，适合讲“类比建模”的边界 |

### 常见坑

- 只看单词长度，但所有 Wordle 都是 5 个字母。
- 用随机切分预测报告人数，造成时间泄漏。
- 只预测平均猜测次数，不回答 1-6-X 的分布。
- 给难度等级但不解释对应的单词特征。

## 2024C Tennis Momentum

### 学习定位

这道题适合训练“怎么把一个模糊概念量化”。题目里的 momentum 不是现成字段，学生必须自己定义指标，再用点级数据验证。

| 维度 | 内容 |
| --- | --- |
| 题型 | 时序状态评价 + 统计检验 + 拐点预测 |
| 核心模型 | 滑动窗口、二项模型、随机森林/HMM、统计检验 |
| 适合课程 | 课程14 描述统计、课程15 特征工程、课程18 回归/分类、课程10 图表 |
| 本地附件 | `Wimbledon_featured_matches.csv`、`data_dictionary.csv` |

### 小白版任务

给定 2023 Wimbledon 男单若干场比赛的逐点数据，完成三件事：

1. 定义一个“谁当前更占优”的 momentum 指标。
2. 判断连续得分和优势转换是否只是随机波动。
3. 找出可能预示 momentum 转向的因素，并给教练建议。

### 数据字段

`Wimbledon_featured_matches.csv` 有 7284 行、46 列。

关键字段分组：

| 分组 | 字段例子 | 用途 |
| --- | --- | --- |
| 比赛定位 | `match_id`, `player1`, `player2`, `set_no`, `game_no`, `point_no` | 分组和时序排序 |
| 当前比分 | `p1_sets`, `p2_sets`, `p1_games`, `p2_games`, `p1_score`, `p2_score` | 状态变量 |
| 发球因素 | `server`, `serve_no`, `speed_mph`, `serve_width`, `serve_depth` | 修正发球优势 |
| 得分结果 | `point_victor`, `game_victor`, `set_victor` | 目标变量 |
| 技术表现 | `ace`, `winner`, `double_fault`, `unf_err`, `break_pt` | momentum 触发因素 |
| 消耗因素 | `distance_run`, `rally_count` | 体能/压力代理变量 |

### 建模学习脚本

| 学习步 | 学生要做什么 | AI 教练只做什么 |
| --- | --- | --- |
| 读题 | 解释 momentum 为什么不是直接给定的数据 | 追问“你如何量化占优” |
| 拆题 | 拆成指标定义、随机性检验、拐点预测、教练建议 | 检查是否区分评价和预测 |
| 数据 | 按 `match_id` 和 `point_no` 排序，选一场比赛试跑 | 提醒不能把不同比赛直接混成一条序列 |
| 指标 | 设计滑动窗口得分差，并修正发球优势 | 提醒发球方天然更容易得分 |
| 检验 | 用 Runs Test 或模拟检验连续得分是否异常 | 提醒“不能只靠肉眼看图” |
| 预测 | 用上一段窗口特征预测 momentum 是否反转 | 帮学生列候选特征 |
| 论文 | 输出一张 match flow 图和一段给教练的 memo | 检查图表是否服务结论 |

### 编程训练

最低可运行版本：

1. 读取 CSV 和字段字典。
2. 选 `2023-wimbledon-1701` 做单场分析。
3. 构造点级胜负变量：player1 得分为 +1，player2 得分为 -1。
4. 用 5 点或 10 点滑动窗口计算局部优势。
5. 加入发球修正：发球赢分的基准概率不同。
6. 画 match flow 曲线。
7. 标记优势从正到负或负到正的拐点。

必须输出：

- 单场 momentum 曲线。
- 拐点列表。
- 随机模拟或统计检验结果。
- 影响拐点的候选因素表。

### 论文表达训练

小白论文结构：

1. 定义 momentum：不是情绪，而是局部表现优势。
2. 指标构建：滑动窗口 + 发球优势修正。
3. 可视化：用曲线展示比赛走势。
4. 随机性检验：和随机模型对比。
5. 拐点预测：讨论哪些因素可能预示反转。
6. 给教练 memo：怎么识别和应对 momentum 改变。

### 获奖论文路线参考

| 论文 | 模型路线 | 可学点 |
| --- | --- | --- |
| `2401298` | 发球/接发重加权；滑动窗口和 AUC；随机性检验；把 momentum 看作朴素二项模型残差，再用双时间贝叶斯网络预测 | 适合学习“先定义指标，再检验随机性” |
| `2401445` | 用动态比赛指数 DPI 衡量状态；GBDT 估计表现；DTW 对比真实和模拟走势；随机森林/HMM 预测转折 | 适合学习“复杂指标如何写成论文结构” |

### 常见坑

- 把连续赢分直接当成 momentum，没有扣除发球优势。
- 一上来训练复杂模型，但没有定义清楚目标变量。
- 只分析决赛，不验证其他比赛。
- 图画得很漂亮，但没有说明曲线正负代表什么。

## 2025C Olympic Medal Tables

### 学习定位

这道题适合做预测类论文训练。它不只是预测奖牌数，还要求预测区间、首枚奖牌国家、项目重要性和“名帅效应”，非常适合教学生如何拆多任务。

| 维度 | 内容 |
| --- | --- |
| 题型 | 奖牌预测 + 不确定性 + 项目贡献 + 名帅效应 |
| 核心模型 | 随机森林、回归、时间序列、Poisson/Monte Carlo、分类模型 |
| 适合课程 | 课程15 特征工程、课程18 回归、课程19 时间序列、课程24 模型评价 |
| 官方题面 | [COMAP: Models for Olympic Medal Tables](https://www.comap.org/membership/member-resources/item/models-for-olympic-medal-tables) |

### 小白版任务

给定历届夏季奥运数据，完成四件事：

1. 预测 2028 洛杉矶奥运各国金牌数和总奖牌数。
2. 给预测结果附带不确定性区间。
3. 判断哪些未获奖国家可能首次获奖。
4. 分析项目设置、主场效应、名帅效应对奖牌的影响。

### 数据设想

官方题面说明提供夏奥奖牌榜、主办国家、项目数量以及运动员个人结果数据。接入时可把字段拆成四张表：

| 表 | 字段例子 | 用途 |
| --- | --- | --- |
| 奖牌表 | `year`, `noc`, `gold`, `silver`, `bronze`, `total` | 预测目标 |
| 主办国表 | `year`, `host_noc`, `city` | 主场效应 |
| 项目表 | `year`, `sport`, `event_count` | 项目结构变化 |
| 运动员表 | `year`, `noc`, `sport`, `medal`, `athlete` | 项目贡献与名帅效应 |

建议派生特征：

- 上一届金牌/总奖牌。
- 最近三届移动平均。
- 是否主办国。
- 参赛运动员数量。
- 某国优势项目数量。
- 某项目新增/删除。
- 历史是否从未获奖。

### 建模学习脚本

| 学习步 | 学生要做什么 | AI 教练只做什么 |
| --- | --- | --- |
| 读题 | 写清至少 4 个输出：奖牌预测、区间、首奖国家、名帅效应 | 追问每个输出对应哪个模型 |
| 拆题 | 把预测、分类、项目贡献、名帅效应拆开 | 检查任务之间的数据接口 |
| 数据 | 整理国家-年份面板数据 | 提醒国家代码和历史国家变更问题 |
| 特征 | 加入历史表现、主场、项目数量、运动员数量 | 提醒不能偷看 2028 真实结果 |
| 模型 | baseline + 随机森林/回归/Poisson | 帮学生比较解释性和准确性 |
| 区间 | 用 bootstrap、Poisson 或残差模拟给预测区间 | 提醒必须报告不确定性 |
| 论文 | 用图表解释谁会上升、谁会下降、为什么 | 检查结论是否有数据支撑 |

### 编程训练

最低可运行版本：

1. 构造国家-年份奖牌面板。
2. 用上一届奖牌数和移动平均做 baseline。
3. 加入主场效应和项目数量特征。
4. 训练随机森林或回归模型预测 `gold` 和 `total`。
5. 用 bootstrap 得到预测区间。
6. 对无奖牌国家做二分类预测。
7. 用特征重要性或 SHAP 解释项目贡献。

必须输出：

- 2028 奖牌预测表。
- 预测区间。
- 可能首次获奖国家列表。
- 项目贡献解释图。
- 模型局限说明。

### 论文表达训练

小白论文结构：

1. 问题重述：奖牌预测不是单一排名，而是一组带不确定性的决策问题。
2. 数据说明：奖牌、主办国、项目、运动员数据如何合并。
3. 预测模型：先 baseline，再机器学习/统计模型。
4. 首奖国家：二分类或概率模型。
5. 项目和主场效应：解释哪些项目影响最大。
6. 名帅效应：必须谨慎，不能把相关直接写成因果。
7. 建议：给国家奥委会的投资方向。

### 获奖论文路线参考

| 论文 | 模型路线 | 可学点 |
| --- | --- | --- |
| `2505964` | 随机森林预测奖牌；Monte Carlo 模拟；Poisson/线性回归；名帅模型 | 任务覆盖完整，适合做主路线参考 |
| `2507817` | 网格搜索随机森林；Logistic 回归预测首奖国家；项目贡献比例；Lasso 估计名帅影响 | 适合学习“预测 + 分类 + 解释”组合 |
| `2510006` | 线性回归、ARIMA、随机森林组合；Poisson 区间；Fisher 检验名帅影响 | 适合学习多模型融合和不确定性 |
| `2510862` | Stacking ensemble；SHAP；PSM-DID 估计名帅效应 | 适合进阶学习因果推断表达边界 |

### 常见坑

- 只给排名，不给预测区间。
- 把金牌数和总奖牌数混成一个目标。
- 忽略项目数量变化和主场效应。
- 名帅效应直接写成因果结论，但没有对照组或干预设计。

## 2025B Sustainable Tourism

### 学习定位

这题适合第二批，因为它非常像国赛综合题：经济、社会、环境三目标同时存在，需要评价、预测和优化组合。

| 维度 | 内容 |
| --- | --- |
| 题型 | 可持续旅游 + 多目标优化 + 政策建议 |
| 核心模型 | 指标体系、AHP/熵权、动态模型、多目标规划 |
| 适合课程 | 课程13 评价模型、课程25 规划、课程32/33 动态系统 |
| 官方题面 | [COMAP: Managing Sustainable Tourism](https://www.comap.org/membership/member-resources/item/managing-sustainable-tourism) |

### 小白版任务

以 Juneau 旅游拥挤为背景，建立一个平衡经济收入、居民压力和环境保护的政策模型。

### 建模学习脚本

| 学习步 | 学生要做什么 |
| --- | --- |
| 指标体系 | 经济、社会、环境三类指标各选 2-4 个 |
| 评价模型 | 用 AHP/熵权得到综合可持续得分 |
| 预测模型 | 预测游客数量、收入、环境压力变化 |
| 优化模型 | 选择税率、游客上限、财政分配等政策变量 |
| 论文表达 | 写给旅游委员会的政策 memo |

### 获奖论文路线参考

| 论文 | 模型路线 | 可学点 |
| --- | --- | --- |
| `2502617` | 经济、社会、环境三个子模型；SLSQP 求 Pareto 最优 | 适合讲多目标优化 |
| `2503268` | 动态系统 + AHP 综合评价 + 敏感性分析 | 适合讲“评价和动态模型结合” |
| `2504448` | 游客需求模型 + 环境熵权指标 + 动态规划 | 适合讲政策变量如何进入模型 |

### 闯关页字段

每个题目可以先生成 7 关种子：

1. `read_problem`：题目摘要和目标清单。
2. `breakdown`：子问题和输入输出。
3. `data`：字段表和质量检查。
4. `model`：候选模型对比。
5. `code`：最小可运行代码目标。
6. `charts`：图表计划。
7. `paper`：章节结构和 memo/letter。

### 第一版不要做

- 不展示获奖论文全文。
- 不生成完整论文段落。
- 不承诺“照这个做就能拿奖”。
- 不强行使用复杂模型；每题都必须保留 baseline。
