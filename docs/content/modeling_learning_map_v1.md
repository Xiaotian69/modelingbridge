# 数学建模全流程学习地图 v1

目标用户：完全小白、会一点 Python 但不会建模、准备参加国赛/美赛的本科队伍。

产品原则：

- 先让学生理解“为什么这样建模”，再讲公式和代码。
- 每个模型单元都同时训练：建模判断、编程实现、论文表达。
- AI 只做教练：提示、追问、检查、复盘，不生成可提交论文。

## 总体路线

| 阶段 | 学习目标 | 课件来源 | 训练产物 |
| --- | --- | --- | --- |

| 1. 读题与拆题 | 把题目拆成对象、目标、约束、数据、输出 | 课程12、第17节课 | 题目理解卡、问题拆解表 |

| 3. 评价模型 | 掌握 AHP、熵权法、TOPSIS 的适用场景 | 课程13、课程13配套资料 | 指标体系、权重表、排名与稳健性 |
| 4. 预测模型 | 掌握时间序列、短期预测、回归预测 | 课程18、课程19、课程20、课程21 | 预测结果、误差指标、残差图 |

## 模块设计

### 0. 入门与比赛认知

小白要先懂三件事：数模不是套公式，比赛不是只拼代码，论文不是最后一天才写。

| 内容 | 设计 |
| --- | --- |
| 建模 | 用“现实问题 → 数学问题 → 计算结果 → 现实建议”解释整个流程 |
| 编程 | 只讲代码在比赛里的作用：清洗数据、运行模型、画图、复现实验 |
| 论文 | 说明论文是“把判断过程写清楚”，不是把代码结果堆上去 |
| 练习 | 给一段校园问题，让学生判断对象、目标、限制、输出 |
| 课件 | `课程1：数模入门及美赛全知解读.pdf`、`课程2：数模美赛解题流程启蒙(1).pdf` |

### 1. 读题与拆题

小白常见错误是刚看到题就问“用什么模型”。本模块要训练先读懂题。

| 内容 | 设计 |
| --- | --- |
| 建模 | 背景、对象、目标、约束、数据、输出六要素 |
| 编程 | 暂不写代码，只写未来需要的数据表和字段 |
| 论文 | 训练“问题重述”和“问题分析”的区别 |
| 练习 | 国赛/美赛题面改写成一句话摘要，再拆 2-4 个子问题 |
| 课件 | `课程12：基础阶段真题初析.pdf`、`第17节课：2023、2024年赛题深析.pdf` |

### 2. 数据与统计

先让学生会看数据，再谈模型。

| 内容 | 设计 |
| --- | --- |
| 建模 | 区分已有数据、待获取数据、假设数据；判断字段单位和粒度 |
| 编程 | Pandas 读取、缺失率、异常值、描述统计、简单可视化 |
| 论文 | 数据来源、预处理、统计特征、异常处理说明 |
| 练习 | 给一张简化数据表，要求写字段含义、缺失处理、统计图 |
| 课件 | `课程14：描述性统计.pdf`、`课程16：假设检验与分布拟合.pdf`、`假设检验计算器.html` |

### 3. 评价模型

评价类题是小白最适合入门的模型族，因为流程清晰、论文容易写完整。

| 内容 | 设计 |
| --- | --- |
| 建模 | 指标体系、效益型/成本型、主观权重/客观权重、排名稳健性 |
| 编程 | 熵权法、TOPSIS、AHP，一定输出权重、得分、排名 |
| 论文 | 指标解释先于公式；排名后必须说明敏感性和局限 |
| 练习 | 食堂评价、城市宜居、葡萄酒评价简化版 |
| 课件 | `课程13：评价模型基础.pdf`、`课程13配套资料/1.熵权法.py`、`课程13配套资料/2.topsis.py` |

### 4. 预测模型

预测类题要让学生理解：预测误差会影响后续决策。

| 内容 | 设计 |
| --- | --- |
| 建模 | 趋势、周期、外生变量、baseline、训练/测试时间划分 |
| 编程 | ARIMA/指数平滑/回归 baseline，输出 MAE、RMSE、预测曲线 |
| 论文 | 先描述时间趋势，再解释模型选择和误差 |
| 练习 | 共享单车需求、出租车早高峰需求、销量预测 |
| 课件 | `课程18：回归分析综合.pdf`、`课程19：时间序列预测.pdf`、`课程20：短期预测.pptx`、`课程21 ：短期预测实战.pdf` |

### 5. 分类与聚类

让学生明白“分类有标签，聚类没标签”，不要把两者混用。

| 内容 | 设计 |
| --- | --- |
| 建模 | 特征工程、标签定义、类别不平衡、聚类解释 |
| 编程 | sklearn Pipeline、随机森林、KMeans、轮廓系数、特征重要性 |
| 论文 | 分类结果不能只报准确率；聚类类名必须来自特征解释 |
| 练习 | 中小微企业风险分类、古代玻璃分类、城市分群 |
| 课件 | `课程15：特征工程.pdf`、`课程22：贝叶斯与分类模型.pdf`、`第23节课：聚类分析.pdf` |

### 6. 优化模型

优化题的核心不是求解器，而是能不能把现实约束写对。

| 内容 | 设计 |
| --- | --- |
| 建模 | 决策变量、目标函数、硬约束、软约束、整数变量 |
| 编程 | PuLP/scipy.optimize/networkx，输出求解状态、目标值、决策矩阵 |
| 论文 | 每条约束都要有现实解释；结果必须检查可行性 |
| 练习 | 应急物资调度、共享单车调度、交巡警平台、TSP |
| 课件 | `课程25：常见规划.pptx`、`课程26：图论优化.pdf`、`课程29：网络优化.pptx`、`课程30：TSP旅行商问题.pdf` |

### 7. 机理模型

机理题适合进阶，不建议小白一开始就学。

| 内容 | 设计 |
| --- | --- |
| 建模 | 状态变量、变化率、参数、初值、单位一致性 |
| 编程 | `scipy.integrate.solve_ivp`、差分迭代、参数敏感性 |
| 论文 | 每个方程必须解释现实含义，参数表必须完整 |
| 练习 | SIR、软着陆概念版、交通流、压力控制 |
| 课件 | `课程32：微分方程.pdf`、`课程33：差分方程模型+案例讲解.pdf` |

### 8. 论文表达

论文训练要贯穿全流程，而不是最后收尾。

| 内容 | 设计 |
| --- | --- |
| 建模 | 论文每一节对应前面某个判断：题目、假设、数据、模型、结果、检验 |
| 编程 | 图表导出、表格导出、实验日志、代码可复现 |
| 论文 | 摘要、问题重述、假设、符号、模型、结果、灵敏度、优缺点 |
| 练习 | 拆 3 篇优秀论文摘要结构，只输出结构标签，不复制正文 |
| 课件 | `课程3：美赛各版块高分写作套路.pdf`、`课程10：美赛优秀论文绘图教学.pdf`、`课程11：美赛高分写作&排版速成.pdf`、`2025美赛论文模版【公众号：数模加油站】.docx` |

## 第一批可上线内容

建议先做 6 个模型单元：

1. 熵权法 + TOPSIS
2. AHP
3. 时间序列预测
4. 回归 / 随机森林
5. 线性规划 / 整数规划
6. 聚类分析

每个单元先做到：

- 什么时候用
- 小白直觉解释
- 输入输出
- 最小代码思路
- 论文怎么写
- 常见坑
- 一道经典题练习

后续再补网络流、TSP、微分方程、差分方程和智能优化。
