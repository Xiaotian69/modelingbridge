# 轻叙事方向选项（MVP 后评估）

> 性质：方向探索备用文档，不进入当前 MVP 实现  
> 前提条件：核心学习流程验证有效 + 用户研究数据支持游戏化包装后再启动  
> 合规底线：叙事层是"包装"，不改变任何学习逻辑和合规边界；叙事文案本身也适用禁用表述清单

---

## 选方向前的判断框架

在选择任何叙事方向之前，需要满足以下前提条件：

1. **内容验证优先**：7 关学习框架的完课率和用户反馈达标（建议基线：完课率 >40%，用户评分 >4.0）。
2. **用户调研支持**：有数据显示目标用户（大学数学建模参赛者）对游戏化包装有正面反应，而非觉得"不专业"。
3. **工程成本可控**：叙事包装不超出 1 名前端工程师 2 周的工作量（超出则优先级不足）。
4. **合规风险可控**：叙事文案通过合规审查，不引发"代替参赛"或"AI 代写"的联想。

---

## 方向一：建模训练所

### 核心概念

把闯关过程包装为"进入一间建模训练所完成培训任务"。每关是一个"训练科目"，完成后获得"科目认证"。没有故事人物，没有剧情线，只是换了一套更有仪式感的措辞。

### 文案风格示例

| 原文案 | 叙事版 |
|--------|--------|
| 第 1 关：读题破冰 | 科目 01：题目研读 |
| 通关并进入下一关 | 完成本科目，进入下一科目 |
| 已通关 ✓ | 科目认证 ✓ |
| 进度：3/7 关 | 进度：3/7 科目 |
| AI 教练提示 | 训练指导 |

### 适合的用户

偏向理工科风格，希望感受"系统化训练"仪式感，但不需要剧情的用户。

### 可能的收益

提升用户对平台"专业感"的感知；"科目认证"比"已通关"更有成就感。

### 可能的风险

与现有功能文案差距小，改动成本低但差异化也低，用户可能感知不到明显变化。

### 对学习逻辑的影响

零影响。只是文案替换，无需修改任何前端逻辑。

### 实现成本估算

文案替换：0.5天。无需额外前端开发。

---

## 方向二：建模侦探社

### 核心概念

把每道题包装为一个"案件"，学生是"侦探"，建模过程是"侦破案件"的步骤。每关是"调查步骤"，最终"结案"（提交通关报告）。不需要叙事人物，只用语境替换。

### 文案风格示例

| 原文案 | 叙事版 |
|--------|--------|
| 数模闯关训练营 | 建模侦探社 |
| 第 1 关：读题破冰 | 第一步：接手案件，研读案情 |
| 通关报告 | 侦查报告 |
| 数据侦查 | 线索收集（第 3 关） |
| 这道题的解法不唯一 | 侦破路径不止一条，你的推理说清楚就有价值 |
| AI 教练 | 资深顾问 |

### 适合的用户

偏向娱乐感，喜欢轻微游戏化体验，但还是以学习为主的用户（大一/大二新手）。

### 可能的收益

"接手案件"的代入感可能提升首次进入时的参与动机；"侦查报告"的定位比"通关报告"更像真实产出物。

### 可能的风险

1. "侦探"语境对理工科学生可能显得幼稚或不专业。
2. "案件"比喻在数学建模（特别是优化类题目）上牵强——建模不全是"侦查"，有时是"设计"。
3. 叙事包装可能让用户对产品定位产生误判（娱乐工具而非学习工具）。

### 对学习逻辑的影响

零影响。只是文案替换，不改变通关条件和AI提示的任何内容。

### 实现成本估算

文案替换：1天。需要对首页、关卡侧边栏、报告页进行文案更新。

## 方向三：零干预（保持现状）

### 核心概念

不加任何叙事包装。当前版本的文案（"第 X 关：XXX"、"通关并进入下一关"等）已经足够清晰，对目标用户（理工科大学生）不存在吸引力不足的问题。

### 适合的用户

所有目标用户。理工科学习者通常更重视"是否有用"，不依赖叙事动机。

### 可能的收益

1. 零额外开发成本。
2. 不引入任何合规风险。
3. 专注于内容和功能质量，这才是用户留存的核心驱动力。

### 可能的风险

首次进入的"第一印象"可能偏平淡，需要靠内容质量本身建立吸引力。

### 对学习逻辑的影响

零影响。

### 实现成本估算

0 成本。

---

## 三个方向对比

| 维度 | 方向一：建模训练所 | 方向二：建模侦探社 | 方向三：零干预 |
|------|-----------------|-----------------|-------------|
| 目标用户契合度 | 高（理工科风格）| 中（偏娱乐化）| 最广 |
| 专业感 | 高 | 中-低 | 高 |
| 合规风险 | 低 | 中（需审查）| 最低 |
| 实现成本 | 极低 | 低 | 零 |
| 差异化明显度 | 低 | 中 | — |
| 推荐优先级 | P2 | P3 | P1（当前默认）|

---

## 实施建议

**MVP 阶段（当前）**：使用方向三（零干预），专注内容和功能验证。

**内容验证通过后（第二阶段）**：若完课率偏低且用户反馈提到"缺乏吸引感"，优先考虑方向一（建模训练所），成本极低。

**不推荐方向二（建模侦探社）**在没有用研数据支持的情况下启动，因为风险大于收益。

## 附：叙事层通用合规检查清单

任何叙事包装文案在上线前必须通过以下检查：

- [ ] 未出现"保奖/提高获奖率/一键论文/降AIGC"等表述
- [ ] 叙事比喻（"案件""任务"等）未暗示"AI替代学生完成建模"
- [ ] 通关报告在叙事层包装后仍然明确标注"学习工具，不可直接提交"
- [ ] AI教练的边界限制（不替学生做最终判断）在叙事层包装后仍然可见
- [ ] 叙事文案不使用"你会赢""打败其他选手"等竞争性表述
