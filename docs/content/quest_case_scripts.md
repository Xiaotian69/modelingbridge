## 副本一：校园共享单车需求预测与调度

**来源案例**：`bike_demand_demo.json`  
**难度**：入门  
**适合人群**：第一次接触"预测 + 优化"两步建模链路的同学  
**核心模型**：时间序列预测（ARIMA / 回归 / 树模型）+ 线性规划调度

---

### 关 1｜读题破冰

**题目材料摘要**

某高校共享单车在上下课高峰出现"有车无桩、有桩无车"的失衡现象。给定历史订单与区域信息，要求预测未来一周各区域需求并提出调度方案，使缺车率与空驶成本综合最优。

**学生输入引导**

- 用一句话说清楚：这道题"给了什么"、"要你算什么"、"最后交什么"？
- 圈出你不确定含义的词：区域级 vs 站点级；一次性调度 vs 连续调度；"调度成本"如何定义？
- 判断题型：这是预测题、优化题，还是两者都有？依据是什么？

**AI 教练提示（3 条）**

1. "你说这道题是'预测+调度'，这两步的顺序是什么？预测的结果如何传入调度模型？你能描述一下这个接口吗？"
2. "题目里有没有说怎么定义'调度成本'？如果没有，你打算怎么假设？假设不同会怎么影响结论？"
3. "你能用一句话说清楚，如果只做预测、不做调度，这道题会丢掉哪些分数？"

**常见错误**

- 把这道题当成纯预测题，忽视了调度方案的输出要求。
- 不区分"区域级"和"站点级"数据粒度，导致后续模型输入维度设置错误。

**通关产物示例**（结构示意，非完整段落）

```
题目摘要（学生自写，约 80 字）：
  - 输入：历史订单（时间戳/区域/量）、天气、节假日
  - 小问 A 输出：7天×各区域×各时段 的需求预测矩阵
  - 小问 B 输出：各区域调入/调出量、总成本、KPI 对比
  - 疑问清单：① 调度成本定义 ② 数据粒度 ③ 是否允许多次调度
```

### 关 2｜拆解任务

**学生输入引导**

- 把这道题拆成至少 2 个子问题，写出每个子问题的输入/输出。
- 两个子问题之间的"接口"是什么？（预测输出的是什么格式，调度模型需要什么格式的输入？）
- 如果只能做一个子问题，你会选哪个？为什么？

**AI 教练提示（3 条）**

1. "小问 A 的输出是一个矩阵——你知道这个矩阵的行、列、值分别代表什么吗？说清楚维度，才能继续往下走。"
2. "你说预测用历史数据，调度用预测结果——如果预测有误差，误差会怎么传递到调度方案？这个问题在论文里要讨论。"
3. "你的子问题 B（调度）有哪些约束？约束没列全是建模失分的常见原因，先列一张约束清单。"

**常见错误**

- 小问 A、B 的接口没有定义清楚，导致代码阶段两个模块的数据格式不兼容。
- 把"讨论"小问（模型局限、假设检验）当成附录而非独立子问题，导致论文结构松散。

**通关产物示例**

```
子问题拆解表（学生自填）：
  子问题 A：需求预测
    输入：历史订单矩阵 + 天气特征 + 节假日标记
    输出：future_demand[7天 × n_zones × 24h]（含误差范围）
    难度：中等（特征工程 + 交叉验证）

  子问题 B：车辆调度
    输入：future_demand + 当前库存 + 距离/成本矩阵
    输出：dispatch_matrix[n_zones × n_zones] + 总成本 + KPI
    难度：中等（线性规划建模）

  依赖关系：B 的输入依赖 A 的输出，A 必须先完成
```

### 关 3｜数据侦查

**学生输入引导**

- 列出三栏数据清单：① 题目附件已提供、② 需外部获取（来源）、③ 需假设（依据）。
- 时序数据必检项：时间是否连续？有没有跳空或重复？各区域数据量是否均衡？
- 哪类数据如果质量差、对你的预测模型影响最大？

**AI 教练提示（3 条）**

1. "你说要用天气数据，来源是哪里？你能在论文中公开引用这个来源吗？来源不清楚的外部数据不能直接用。"
2. "你的时序数据有没有节假日跳空？如果有，你是删掉这些时间点还是做插值？两种处理方式对结果影响不同，先想清楚。"
3. "各区域的数据量均衡吗？样本极少的区域（比如某个区域只有 10 条记录）你打算怎么处理——单独建模还是合并？"

**常见错误**

- 天气数据与订单数据时区未对齐就直接合并，导致特征错位。
- 以为题目给了所有需要的数据，没有检查字段含义，把"区域编号"当成连续变量输入模型。

**通关产物示例**

```
数据清单（学生自填）：
  已有（题目附件）：
    - 历史订单：时间戳/区域编号/订单量，约 XX 行，时间范围 XX
    - 区域信息：区域编号/邻接关系，XX 个区域

  外部获取：
    - 天气数据：气象局公开数据，来源：[URL]，需对齐时区
    - 节假日标记：根据公历人工整理

  需假设：
    - 区域间距离/成本矩阵：假设成本与地图直线距离成正比，系数=XX元/公里

数据风险：天气数据时区对齐错误 → 直接导致特征无效 → 模型预测能力下降
```

### 关 4｜模型选择

**学生输入引导**

- 子问题 A（预测）：候选模型至少 2 个，并做对比。推荐从 ARIMA、回归、树模型中选。
- 子问题 B（调度）：候选方案至少 2 个，并做对比。推荐从启发式规则、线性规划、整数规划中选。
- 为什么不选 Baseline（历史均值 / 不调度）？Baseline 能给你什么基准？

**AI 教练提示（3 条）**

1. "你选了 XGBoost 做预测，但你有没有先跑一个 ARIMA 基准？如果 XGBoost 只比 ARIMA 好一点点，但实现复杂得多，这个额外复杂度值得吗？"
2. "你选线性规划做调度，你能写出目标函数和全部约束条件吗？写不出来就还不能进入下一关。"
3. "调度量必须是整数吗？如果必须，你选的是 LP 还是 MILP？两者的计算代价差距很大。"

**常见错误**

- 不建 Baseline，直接上复杂模型，无法说明模型带来了多少提升。
- 调度模型写了目标函数但漏掉非负约束或供需平衡约束。

**通关产物示例**

```
模型对比表（学生自填）：
  子问题 A — 预测模型对比：
    | 指标       | 历史均值 | ARIMA | 多元回归 | XGBoost |
    |-----------|---------|-------|---------|---------|
    | 数据需求   | 低       | 低    | 中       | 高      |
    | 实现难度   | 极低     | 低    | 中       | 高      |
    | 可解释性   | 高       | 中    | 高       | 低      |
    | 预期精度   | 基准     | 中    | 中高     | 高      |

  最终选择：[学生自己判断并填写理由，至少3句话]

  子问题 B — 调度方案：
    目标函数：min Σ c_ij * x_ij
    约束：供给约束 + 需求约束 + 非负约束
    最终选择：线性规划（scipy / PuLP），理由：[学生自填]
```

### 关 5｜代码起步

**学生输入引导**

- 先读入数据，打印行数/列数/缺失值数量/时间范围。
- 实现 `build_features(df)` 函数：提取小时、星期几、滞后特征（lag-1h、lag-24h）。
- 跑通最简单的预测模型（哪怕只是 ARIMA(1,1,1)），打印 MAE。
- 对比你的 MAE 和历史均值 Baseline 的 MAE，两者差多少？

**AI 教练提示（3 条）**

1. "你的滞后特征（lag-24h）在测试集里有没有数据泄露？测试集的 lag 特征只能用训练集结束之前的数据，你检查了吗？"
2. "你的模型 MAE 是 X，Baseline MAE 是 Y——X 比 Y 好多少个百分比？这个提升量值得用更复杂的模型来换吗？"
3. "你的调度模型跑出来结果是 Optimal 吗？如果是 Infeasible，通常原因是供给总量 < 需求总量，先检查这个。"

**常见错误**

- 时序数据随机划分训练/测试集，导致测试集使用了未来数据（数据泄露）。
- 调度量计算出负数没有处理，直接进入论文。

**通关产物示例**

```
代码跑通记录（学生自填）：
  数据读入：✓  行数: XX  列数: XX  缺失: XX%
  特征工程：✓  特征列表: [hour, dayofweek, lag_1h, lag_24h, is_holiday]
  预测模型：✓  ARIMA(1,1,1)  MAE=XX.X（Baseline MAE=XX.X，提升 X%）
  调度模型：✓  PuLP status=Optimal  总成本=XX元
  合理性检验：[学生自己写判断，至少1句]
```

### 关 6｜图表表达

**学生输入引导**

- 图 1：真实需求 vs 预测需求折线图（选 1—2 个区域展示），加置信区间阴影。
- 图 2：区域需求热力图（行=区域，列=时段，颜色=需求强度）。

- 图 4：调度前后 KPI 对比柱状图（缺车率/总成本）。
- 每张图必须写一句"这张图支撑了哪个结论"。

**AI 教练提示（3 条）**

1. "你的图 2 热力图，颜色越深代表需求越高还是越低？图里有图例说明吗？评委不能猜。"

- 雷达图没有闭合（最后一个点没有和第一个点连接）。

## 副本二：校园食堂服务质量综合评价

**来源案例**：`evaluation_topsis_demo.json`  
**难度**：入门  
**适合人群**：第一次接触综合评价类建模的同学  
**核心模型**：熵权法 + TOPSIS

---

### 关 1｜读题破冰

**题目材料摘要**

某高校有多个食堂，需对其服务质量综合评价并排序，找出表现最好和最需改进的食堂。给定若干评价指标（菜品种类、等待时间、卫生评分等）和各食堂数据，要求建立综合评价模型并给出排名和改进建议。

**学生输入引导**

- 这道题的"最终交付物"是什么格式——一个数、一张排名表，还是一份建议？
- 题目给的数据是评分（1-5分）还是测量值（分钟/个数）？不同格式预处理方式不同。
- "越大越好"还是"越小越好"——每个指标你怎么判断？

**AI 教练提示（3 条）**

1. "你说这道题的目标是'给食堂排名'，但排名是手段，目的是什么？评委想看你的结论对管理有什么用。"
2. "你列的指标里，有没有两个指标可能高度相关（比如'菜品种类多'和'价格满意度低'可能负相关）？相关性会影响熵权法的权重。"
3. "题目里有没有说谁提供了数据——是学校行政、还是问卷调查？数据来源会影响你在论文里怎么说明数据代表性。"

**常见错误**

- 把所有指标都当成效益型（越大越好），忘记"等待时间"是成本型（越小越好）。
- 指标选太多（超过 10 个），导致熵权法权重失真、结论不稳健。

**通关产物示例**

```
题目摘要（学生自写，约 80 字）：
  评价对象：4个食堂（A/B/C/D）
  给定：6个评价指标的原始数据矩阵（行=食堂，列=指标）
  输出：综合评分/排名 + 针对排名靠后食堂的改进建议
  疑问：①数据来源（问卷vs测量）②指标是否允许加主观权重③指标相关性
```

---

### 关 2｜拆解任务

**学生输入引导**

- 这道题的建模流程分几步？每步的输入/输出是什么？（提示：标准化→权重→评分→验证）
- 稳健性检查是独立的子问题还是验证步骤？为什么？
- 如果题目还要求"给出改进建议"，这是第几步？它依赖前面哪些结果？

**AI 教练提示（3 条）**

1. "你把流程拆成了4步，每步的输出格式是什么——是矩阵还是向量还是一个数？把格式写清楚，代码阶段才不会出现维度错误。"
2. "熵权法和TOPSIS可以并行吗？还是必须先跑完熵权法才能跑TOPSIS？依赖关系是什么？"
3. "你的稳健性检查需要用到TOPSIS的结果，所以它必须在TOPSIS之后——但你打算在这一关就设计稳健性检查方案吗，还是等到代码阶段？"

**常见错误**

- 忘记把"改进建议"纳入子问题拆解，导致论文结论章节空洞。
- 稳健性检查方案没有在建模阶段设计好，导致代码阶段临时拼凑。

**通关产物示例**

```
建模流程（学生自填）：
  步骤1：指标选取与类型标注（B/C）
    输入：原始指标描述  输出：指标清单（含类型标注）

  步骤2：极差标准化
    输入：原始数据矩阵 [n食堂 × m指标]  输出：标准化矩阵Z [n × m]，值域[0,1]

  步骤3：熵权法权重计算
    输入：标准化矩阵Z  输出：权重向量w [m]，总和=1

  步骤4：TOPSIS综合评价
    输入：Z和w  输出：相对接近度C [n]，排名

  步骤5：稳健性检查
    输入：Z和w  输出：100次扰动下各食堂排名分布

  步骤6：结论与改进建议
    输入：排名+各食堂指标弱项  输出：差异化改进建议
```

### 关 3｜数据侦查

**学生输入引导**

- 检查数据矩阵：是否有某列所有值完全相同？（如果有，该指标在熵权法中权重为0，需要处理）
- 是否有缺失值？熵权法和TOPSIS均不能处理NaN。

**AI 教练提示（3 条）**

1. "你的数据矩阵有没有某一列所有食堂得分完全相同？这列指标在熵权法里权重会变成0——如果这个指标你认为很重要，说明数据可能有问题。"
2. "你说数据来自问卷，问卷的样本量是多少？如果不到30人，你需要在假设里说明'数据代表性可能有限'。"
3. "各列的量纲一样吗？等待时间（分钟）和评分（1-5）量纲不同，但标准化之后就都在[0,1]范围内了，这是标准化的作用之一。"
