## 3. 三门课程

### 3.1 TOPSIS 综合评价（与 AHP 衔接）

- 故事接着 AHP 课：小林选定研究所后，在附近五套合租房中挑选（月租、通勤为成本型，面积、配套为效益型）。
- 衔接方式：第 4 节直接用 AHP 求 4 个准则的权重（复用已验证的 `ahp/math.ts`，CR = 0.0038），并放“回顾 · 层次分析法”卡片链到 `/learn/ahp#weights`；AHP 课第 8 节和结尾新增“下一门：TOPSIS”。讲清分工：AHP 定权重，数据和 TOPSIS 评方案。
- 内容：指标方向（含适中型的处理）→ 向量标准化（手算 3-4-12 例子）→ AHP 加权 → 正负理想解（平面图）→ 距离与贴近度 → 熵权法（与 AHP 权重对比）→ Python → 稳健性（权重敏感、方向写反时最贵的房子 C = 1、**逆序现象**：加入只排第 4 的“己”后第一名由丁变乙、“max − x 正向化”与经典做法结果不同）→ 自测 → 竞赛流程。
- 应用：七关实战“校园食堂服务质量综合评价”（熵权 + TOPSIS 现成案例）。

### 3.2 回归分析

- 案例：校园奶茶店两周销量、最高气温、是否周末。
- 内容：散点图与相关系数 → 模型与残差 → 最小二乘（5 点手算表 + 偏导推导选读）→ R² 与残差图（四个周末残差全为正，引出遗漏因素）→ 多元回归与虚拟变量（系数、标准误、t、P、调整 R²；气温系数 4.33 → 6.98 的**遗漏变量偏差**）→ 预测与 **95% 预测区间**（235–265 杯）、外推风险（0 ℃ 得负销量）→ Python（statsmodels）→ 相关与因果、异常值（一个活动日使斜率 4.33 → 1.54、R² 0.533 → 0.030）、非线性、过拟合、共线性 → 自测 → “先预测、后优化”，链到线性规划。
- 说明：方法索引中“回归 / 随机森林”现在指向本课；本课只讲线性回归，课内明确说明随机森林见方法速查。

### 3.3 图论与网络优化

- 案例：招新日的校园地图（7 个地点、12 条路），新生从宿舍区去招新广场；协会沿路铺广播线。
- 地图经过专门设计，使每个答案唯一并且有教学点：4 段路的最短路（1080 米）胜过 2 段路（1130 米）；Dijkstra 中教学楼 790 → 750、招新广场 1110 → 1080 被松弛；Kruskal 恰好跳过一条成环边；图书馆—教学楼施工后最短路改道（1110 米）；最小生成树中宿舍区到体育馆要绕 1360 米（最短路 850 米）。
- 内容：图、权、度与握手定理 → 邻接矩阵 / 邻接表 → Dijkstra 的思想与正确性论证（为什么需要非负权）→ 逐步表与实验 → 最小生成树与 Kruskal → 最短路树与最小生成树的区别、分组性质与 Prim → Python（自己写的堆版 Dijkstra + networkx）→ 负权（反例）、有向图、旅行商、网络流（**明确说明本课未讲网络流**）→ 自测 → 竞赛流程，链到线性规划。

## 4. 数学独立复核

原则沿用 AHP：**课文、实验、题目中的每个数字都由代码从 `data.ts` 计算，不手填**；TypeScript 测试只读取 Python 独立实现生成的夹具，自己不算期望值。

| 课程 | 独立实现（与 TS 代码路径不同） | 覆盖 |
|---|---|---|
| TOPSIS | `verify_topsis.py`：numpy 范数、`scipy.spatial.distance.cdist` 求距离、`scipy.stats.entropy` 求熵、`numpy.linalg.eig` 求 AHP 权重 | 课程 6 种情形（AHP / 等权 / 熵权 / 六套房 / 方向写反 / 正向化变体）+ 200 个随机问题（3–8 方案、2–6 指标、随机方向和权重） |
| 回归 | `verify_regression.py`：`scipy.stats.linregress`、statsmodels OLS（并与 `numpy.linalg.lstsq` 互相断言） | 一元 / 多元系数、标准误、t、P、R²、调整 R²、残差、活动日、预测与 statsmodels 的 95% 预测区间；150 个随机问题；60 组 Student t 分布 CDF / 分位数与 `scipy.stats.t` 对照 |
| 图论 | `verify_graph.py`：networkx 的 Dijkstra、Bellman–Ford、Kruskal、Prim；另用 heapq 记录确定顺序 | 全部点对最短距离、最短路径、确定顺序、最小生成树边集与总长、施工情景、负权反例；150 个随机连通图 |

此外：

- **文字描述也逐条复核**。“丁没有哪一项是最好的”“四个周末残差全为正”“周末平均 26.5 ℃、工作日 30.6 ℃”“己只排第 4 却让乙超过丁”“教学楼—体育馆是唯一被跳过的边”等每一句描述数据的话，都在 `content.test.ts` 中用数据重新检验；题目解析里引用的数字同样检验。
- 每道题：参考答案判为正确；每个错误选项都有对应诊断；每个数值错因（如“用了求和归一化”“分子用了 D⁺”“漏了截距”）都确认不会被判为正确，并用学生实际会输入的三位小数验证能触发。
- 三个 Python 夹具重新生成后与提交版本逐字节相同；三个课程配套程序都实际运行过，输出与课文“运行后应得到”一致。
- 所有 KaTeX 公式在 `throwOnError` 下解析通过。
