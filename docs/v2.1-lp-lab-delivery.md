## 功能

- 地址 `/learn/linear-programming/lab`。默认为教材案例 max 40x + 50y，切割 2x + y ≤ 100，装配 x + 2y ≤ 80，最优 (40, 20)、2600 元。
- 可调：两种产品的利润（0–80）；两条资源约束中每种产品占用的工时（0–4，步长 0.5）与可用工时（0–150）；可选的最低订单 x + y ≥ d（0–150）。
- 每次调整实时重算并重画：可行域、约束线、最优利润等值线、最优点或最优边、角点利润表、资源剩余。
- 四种结果如实区分：唯一最优（用完的约束、剩余资源、两个利润的“最优点不变范围”）；多重最优（与哪条边平行、整条边利润相同；若沿无界方向利润系数为 0，说明最优解是一条射线）；无可行解（算出资源能达到的最大总产量并与订单比较）；无界（指出可无限增加的方向，并说明这通常意味着漏了约束）。
- 预设：恢复默认 / 多重最优 / 无可行解 / 无界。
- 入口：教材第 3 节交互图下方、第 6 节末尾；精讲目录线性规划卡片；站内搜索。返回：从教材进入时用浏览器历史回到原阅读位置（实测离开 3669 px，返回 3669 px）；直接打开时链接到对应小节。
- 手机：图和结论标题固定在顶部，拖动下方滑块时始终可见，完整解释在滑块之后；深浅主题沿用设计变量；实验室本身没有动画，页面过渡沿用统一动效（减少动态时关闭）。

## 数学

- 已验证的教学求解器 `solver.ts` 只覆盖固定的两资源模型，在其参数范围内永远可行、有界；它没有修改。
- 实验室使用独立的 `learning/lab/lp2d.ts`：求所有约束线（含坐标轴）的交点并保留可行者为角点；可行域在第一象限，非空必有角点，故无角点即无可行解；用可行域的无界方向（回收锥的极射线）判断无界；否则最优值在角点取得，并列角点之间整条边最优。
- 验证：
  - `lab/verify_lp2d.py` 用 SciPy HiGHS 求解 409 个模型（含全部预设与 400 个随机模型），记录状态（最优 / 无可行解 / 无界）与最优值；另用 4 个辅助线性规划求最优解集合上 x、y 的范围，独立判断最优解是否唯一。TS 结果与之逐一一致（唯一 294、多重 11、无可行解 97、无界 7）。唯一最优的数值宽度最大 2.1e-5，真正的并列最优宽度最小 10，判定阈值 1e-3 两边都远离。
  - 在已验证求解器的整个参数域上抽取 900 组参数：最优值、最优角点集合、可行域角点集合与 `solver.ts` 完全一致。
  - “最优点不变范围”在 120 个模型上回代验证：范围内最优点不变，越过边界 1 个单位后最优点改变。
