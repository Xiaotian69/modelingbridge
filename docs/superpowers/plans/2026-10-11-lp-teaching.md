# 线性规划教学样板实施计划

> 执行方式：本会话按 executing-plans 逐项实施；按用户要求，完成可体验样板后暂停。

**目标：** 让初学者能解释、手算、编程求解并检验一个完整的资源分配模型。

**架构：** 保留 React Router/Vite 静态架构。课程采用结构化正文数据；求解器、题库、判分、存储、阅读组件分离。旧知识卡移到 reference，兼容原有锚点。无需服务器或在线 AI。

**技术：** React、TypeScript、SVG、KaTeX、Python/SciPy 独立验算、Vitest。

## 诊断与设计决策

现有 Learn 页面把学习路线、近年赛题、方法输入输出、论文建议放在同一长页。每个方法内部六个并列卡片没有因果顺序，也没有完整数据、计算结果和操作反馈。保留其速查价值，主入口改为精讲、专项练习、赛题实战三条路径。

比较方案：继续扩充卡片成本低但无法解决叙事；引入 MDX 适合大规模写作但当前仅一章会增加编译链；本轮选择类型化内容块，正文与渲染分离，后续可转 MDX。

课程使用连续正文和固定目录，手机目录折叠；章节内上一节/下一节，保存阅读位置并提供续读入口。未建设下一章不提供虚假入口。阅读位置不等于掌握程度。

## 实施与验收

- [x] 研究记录：GitHub 项目、具体例题、许可分拆、可复现性；PDF 页码及历史局限。原文和 PDF 不进入网站。
- [x] `learning/solver.ts`：两变量两资源非负 LP，边界交点枚举，显示并列最优；整数演示有界枚举。先测试默认 (40,20),2600、零资源、并列最优、非法输入和整数反例。
- [x] `learning/questions.ts`、`grading.ts`、`storage.ts`：审核题库，单选/多选/数值/判断，容差和严格输入，逐步提示、提交解析、本地记录、错题重练。待审题不得发布。
- [x] `learning/content.ts`、`examples/workshop.py`：原创连续课程。变量单位、假设、建模、图解手算、Python、结果检验、灵敏度、整数区别、边界、自测与实战迁移。
- [x] `pages/Learn.tsx`、`Course.tsx`、`Practice.tsx`：三模式入口、目录锚点/续读、独立练习；`ModelReference.tsx` 保留旧内容和其回归测试；仅新增 App 路由。
- [x] `learning/Graph.tsx` 和 `learning.css`：可键盘操作的滑杆、SVG、数值等价说明，桌面/手机、减少动效、公式及代码高亮。
- [x] `python frontend/src/learning/examples/workshop.py` 核实教材答案；用 SciPy 生成独立参数样本验证 TS 求解；运行 `npm test`、`npx tsc --noEmit`、`npm run build`。
- [x] gstack 实测桌面/手机、滑杆、锚点刷新、续读、错误提交/更改答案/重练；截图保存在 `.context`。检查分包、EdgeOne SPA 回退，记录部署端未实际测试边界。
