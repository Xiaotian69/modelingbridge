# 模桥 EdgeOne 香港方向静态试运行

> 分支 feat/edgeone-hk-pilot。本分支不动生产主分支，不购买服务，不配置付款信息。仅为部署准备，**尚未完成上线及国内网络验收**。

## 目的

第一阶段通过腾讯云 EdgeOne Pages（加速区域选择不含中国大陆）部署 React/Vite 静态前端，使用自定义域名后通过校园网、中国移动/联通/电信人工实测。香港轻量服务器暂时不购买。

## 已包含

- frontend/edgeone.json：单页应用路由重写到 index.html，基础响应头。
- 8 个案例 JSON 本地内置；无 FastAPI 服务时案例列表回退读取静态案例，案例详情原本已有对应回退。
- 其他学习页面、七关闯关和浏览器本地学习记录可在纯前端运行。

## 建站时的 Pages 配置

1. 登录 https://pages.edgeone.ai/ ，连接 GitHub 仓库 Xiaotian69/modelingbridge，选择该分支进行预览构建。
2. 项目根目录设置为 **frontend**，Framework 选 Vite / React，构建命令 **npm run build**，发布目录 **dist**。构建平台的相对路径设置可能因 UI 不同而变化，以平台检测结果为准。
3. 若 build 检测失败，检查 frontend 里引用 ../cases 的路径，确保平台的构建上下文可以读取仓库根目录 cases 文件夹；必要时改为在仓库根目录执行 **npm --prefix frontend ci && npm --prefix frontend run build**，产物 **frontend/dist**。
4. 部署区域选 **全球（不含中国大陆）**。根据 EdgeOne 当前政策，大陆访客要用自定义域名测试，默认 pages.dev / edgeone.app 测试域名可能被阻断；不保证跨境质量。
5. 暂不设置 VITE_API_BASE_URL，因为现有 FastAPI 尚未部署。切勿在 VITE_* 环境变量中放 API 密钥。
6. 测试主页、/learn、/quest、/cases、/cases/<slug>、/tools、/records；确认首次进入和刷新皆可打开。

## 第一阶段已知限制

- AI 工作台、备赛方案生成、后端资料下载需要 Python API；纯静态部署时不能作为可用的在线 AI 服务。需在 UI 标示不可用或接入后端后再开放。
- 资源中心目前依赖后端扫描服务器本地资料目录，纯静态方案不可在线列出这些 PDF。后续应使用经授权的资料索引 JSON 与外部存储链接替换。
- 现有学习记录及部分反馈使用浏览器 localStorage；它们不是跨设备、多人共享的协会活动提交系统。
- 公开上线前补充 API 鉴权、成本额度、限流、安全日志；不能把试用码或 AI 密钥当作前端公开配置。
- 正式活动报名/排行榜/成绩需要后端及持久化数据库，并要考虑隐私保护和异常提交。
