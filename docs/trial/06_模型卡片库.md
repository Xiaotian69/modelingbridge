### 卡片 E-01｜AHP 层次分析法

**一句话定义**  
把一个复杂的评价问题拆成多层目标，通过两两比较构建判断矩阵，得到各指标的主观权重。

**适用条件**  
- 指标权重主要来自专家经验或题目给出的重要性描述  
- 评价指标之间有层次结构（可以分级）  
- 通常用于"确定权重"，不单独给出排名，需与 TOPSIS 等结合  

**不适用场景**  
- 指标太多（>9 个）：两两比较矩阵规模为 n²，容易不一致  
- 数据驱动型评价：有客观数据时优先用熵权法

**关键参数**  
- 判断矩阵：每个元素 a_ij 表示"指标 i 相对于 j 的重要程度"（Saaty 1—9 标度）  
- 一致性检验：CR = CI/RI < 0.1（否则需要修改判断矩阵）  
- 权重向量：判断矩阵最大特征值对应的特征向量归一化

**检验方法**  
- 一致性比例 CR < 0.1（必须做，否则权重无效）  
- 对比不同专家给出的判断矩阵，看权重是否稳定

**代码入口**  
```python
import numpy as np
def ahp_weight(matrix):
    eigenvalues, eigenvectors = np.linalg.eig(matrix)
    max_idx = np.argmax(eigenvalues.real)
    w = eigenvectors[:, max_idx].real
    return w / w.sum()  # 归一化
```

**容易踩的坑**  
- 忘记做一致性检验，CR > 0.1 的结果不能直接用  
- 权重要解释"为什么这么比"，不能写完判断矩阵就结束

### 卡片 E-02｜熵权法

**一句话定义**  
利用信息熵原理，根据各指标在评价对象之间的差异程度自动分配权重——差异越大，权重越高。

**适用条件**  
- 有多个指标和多个评价对象的客观数据  
- 不希望依赖主观判断来分配权重  
- 通常与 TOPSIS 搭配使用（先熵权法定权重，再 TOPSIS 排序）

**不适用场景**  
- 各评价对象在某指标上的值完全相同：该指标熵为 1，权重为 0，自动被剔除（实际上这个指标是没有区分能力的，剔除是合理的）  
- 数据量太少（评价对象 < 3 个）：统计意义弱

**关键参数**  
- 比例矩阵：p_ij = z_ij / Σ_i z_ij  
- 信息熵：E_j = -k·Σ_i(p_ij·ln p_ij)，k = 1/ln(n)  
- 差异系数：d_j = 1 - E_j  
- 权重：w_j = d_j / Σd_j

**检验方法**  
- 权重总和是否为 1  
- 权重是否符合直觉（差异大的指标权重应更高）  
- 若某权重异常大，检查该列是否存在极端值影响

**代码入口**  
见 `evaluation_topsis_demo.json` → code_framework 中的 `entropy_weight()` 函数

**容易踩的坑**  
- log(0) 错误：p_ij = 0 时需要加 epsilon（如 1e-9）  
- 忘记先做标准化：熵权法必须在标准化后的矩阵上计算

### 卡片 E-03｜TOPSIS

**一句话定义**  
通过计算每个方案与"最优解"和"最劣解"的距离，得到相对接近度来排名。

**适用条件**  
- 已有标准化后的指标矩阵和权重向量  
- 需要给多个方案（评价对象）排序  
- 指标均已转化为"越大越好"（通过标准化实现）

**不适用场景**  
- 未做标准化就直接用：量纲不同的指标混在一起，距离计算没有意义  
- 评价对象只有 2 个：无法区分正负理想解的差异

**关键参数**  
- 正理想解 A+：加权矩阵每列的最大值  
- 负理想解 A-：加权矩阵每列的最小值  
- 相对接近度：C_i = D-_i / (D+_i + D-_i)，越接近 1 越好

**检验方法**  
- C_i 是否全在 [0,1] 之间  
- 手动验算 1—2 个对象的 D+ 和 D-  
- 做稳健性检查（权重扰动后排名是否稳定）

**代码入口**  
见 `evaluation_topsis_demo.json` → code_framework 中的 `topsis()` 函数

**容易踩的坑**  
- 用原始矩阵而不是加权矩阵来计算距离  
- 把"相对接近度"误称为"得分"，两者含义不同

### 卡片 E-04｜模糊综合评价

**一句话定义**  
用模糊集合描述评价标准，通过隶属度函数将定性判断量化，适合指标含义模糊（如"满意程度"）的评价问题。

**适用条件**  
- 指标的优劣判断本身是模糊的（如"服务态度好""环境舒适"）  
- 题目明确给出了评价等级（如优/良/中/差）  
- 数据来自主观打分，不是精确测量值

**不适用场景**  
- 数据是精确测量值（用熵权法+TOPSIS 更合适）  
- 需要快速给出排名（模糊综合评价计算流程相对复杂）

**关键参数**  
- 评价因素集 U、评语集 V  
- 隶属度矩阵 R（每个因素在各等级的隶属程度）  
- 权重向量 A（各因素重要程度）  
- 综合评判向量：B = A·R

**检验方法**  
- 隶属度函数是否合理（三角形、梯形等形状的选择依据）  
- 综合评判向量 B 的归一化  
- 与其他评价方法对比结果的一致性

**容易踩的坑**  
- 隶属度函数形状随意设定，没有依据  
- 综合得分相近时，模糊综合评价的区分能力弱

### 卡片 P-01｜一元/多元线性回归

**一句话定义**  
建立因变量与一个或多个自变量之间的线性关系，用最小二乘法估计参数。

**适用条件**  
- 因变量与自变量之间有线性关系（可以先看散点图判断）  
- 数据量适中（通常 > 自变量数量的 10 倍）  
- 需要能解释"哪个因素影响更大"（线性回归的系数有直接解释意义）

**不适用场景**  
- 因变量与自变量之间是非线性关系（考虑多项式回归或树模型）  
- 自变量之间高度相关（多重共线性问题，用岭回归或逐步回归）  
- 时间序列数据（有自相关，考虑 ARIMA）

**关键参数**  
- 回归系数及其显著性（p 值 < 0.05 才认为显著）  
- R²：解释方差比例（越接近 1 越好，但不是唯一标准）  
- 残差图：残差应随机分布在 0 附近，若有规律说明模型设定有问题

**检验方法**  
- 残差正态性（QQ 图或 Shapiro-Wilk 检验）  
- 同方差性（残差 vs 预测值散点图）  
- 多重共线性（VIF < 10）  
- 外推时注意：线性关系在数据范围外可能不成立

**代码入口**  
```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error
model = LinearRegression().fit(X_train, y_train)
y_pred = model.predict(X_test)
print(f"MAE: {mean_absolute_error(y_test, y_pred):.4f}")
print(f"系数: {dict(zip(feature_names, model.coef_))}")
```

**容易踩的坑**  
- 高 R² ≠ 预测好：外推时 R² 可能崩塌  
- 没有检验残差分布，模型假设不满足时结论不可信

### 卡片 P-02｜ARIMA 时间序列模型

**一句话定义**  
基于时间序列自身的历史值（AR 部分）和历史误差（MA 部分），加上差分（I 部分）来处理非平稳序列，做短期预测。

**适用条件**  
- 只有时间序列本身（无外部特征）  
- 序列有明显的自相关性（自相关函数 ACF 图有显著尖峰）  
- 数据量适中（通常 > 50 个时间点）  
- 短期预测（长期预测不可靠）

**不适用场景**  
- 有重要的外部影响因素（天气、政策等）→ 考虑 ARIMAX 或回归模型  
- 数据点很少（< 20）：参数估计不可靠  
- 有明显季节性且频率高（每小时数据）→ 考虑 Seasonal ARIMA（SARIMA）

**关键参数**  
- p（AR 阶数）：从 PACF 图确定  
- d（差分次数）：通常 1 或 2，使序列平稳  
- q（MA 阶数）：从 ACF 图确定  
- 选参数方法：AIC/BIC 信息准则（越小越好），或 auto_arima 自动搜索

**检验方法**  
- ADF 检验：序列是否平稳（p 值 < 0.05 说明平稳）  
- Ljung-Box 检验：残差是否为白噪声（p 值 > 0.05 说明没有遗漏的自相关）  
- 滚动验证（rolling CV）：前向预测，不能随机划分

**代码入口**  
```python
from pmdarima import auto_arima
model = auto_arima(train, seasonal=False, stepwise=True)
pred = model.predict(n_periods=len(test))
# 画预测 vs 实际
```

**容易踩的坑**  
- 直接用所有数据训练，用同样数据测试（数据泄露）  
- 差分次数选太多（过度差分）→ 序列变得不可预测  
- 忘记残差白噪声检验，模型残差仍有规律但没发现

### 卡片 P-03｜指数平滑（Holt-Winters）

**一句话定义**  
对历史数据加权平均，越近的数据权重越高，适合有趋势和季节性的时间序列。

**适用条件**  
- 序列有趋势或季节性（如周期性变化）  
- 想要简单快速的预测模型（参数少，容易解释）  
- 作为复杂模型的基准（Baseline）

**不适用场景**  
- 有外部因素影响  
- 非平滑变化（剧烈跳变）的序列

**关键参数**  
- α（水平平滑系数）、β（趋势平滑系数）、γ（季节平滑系数）  
- 所有参数在 [0,1] 之间，越接近 1 越重视近期数据

**代码入口**  
```python
from statsmodels.tsa.holtwinters import ExponentialSmoothing
model = ExponentialSmoothing(train, trend='add', seasonal='add', seasonal_periods=7).fit()
pred = model.forecast(len(test))
```

### 卡片 P-04｜随机森林 / 梯度提升树（XGBoost/LightGBM）

**一句话定义**  
基于决策树的集成模型，能自动处理非线性关系和特征交互，适合有多个影响特征的预测任务。

**适用条件**  
- 有多个自变量（天气、时间特征、区域特征等）  
- 自变量和因变量之间存在非线性关系  
- 数据量较大（通常 > 1000 条）  
- 希望有特征重要性分析支撑论文说明

**不适用场景**  
- 需要精确解释系数含义（树模型的可解释性不如线性模型）  
- 外推场景（预测范围超出训练数据的范围，树模型外推能力弱）  
- 数据量很少（容易过拟合）

**关键参数**  
- 随机森林：`n_estimators`（树的数量）、`max_depth`（树深度）  
- XGBoost：`learning_rate`、`n_estimators`、`max_depth`、`subsample`  
- 超参数调优：GridSearchCV 或 Optuna

**检验方法**  
- 交叉验证 CV（时序数据用 TimeSeriesSplit）  
- 特征重要性（importance_）：解释哪个特征影响最大  
- 学习曲线：检查是否过拟合（训练误差 vs 验证误差）

**代码入口**  
```python
from xgboost import XGBRegressor
from sklearn.model_selection import TimeSeriesSplit
tscv = TimeSeriesSplit(n_splits=5)
model = XGBRegressor(n_estimators=100, max_depth=6, learning_rate=0.1)
for train_idx, val_idx in tscv.split(X):
    model.fit(X[train_idx], y[train_idx])
    print(model.score(X[val_idx], y[val_idx]))
```

**容易踩的坑**  
- 时序数据随机划分训练测试集（数据泄露，测试分数虚高）  
- 超参数没有说明取值依据，评委会问

### 卡片 O-01｜线性规划（LP）

**一句话定义**  
在线性约束条件下，最大化或最小化一个线性目标函数，是最经典的优化模型。

**适用条件**  
- 目标函数是决策变量的线性函数  
- 所有约束条件都是线性不等式或等式  
- 决策变量可以取连续实数值

**不适用场景**  
- 决策变量必须取整数（→ 整数规划）  
- 目标函数或约束含有非线性项（→ 非线性规划）

**关键参数**  
- 决策变量：x_1, ..., x_n（含义、取值范围）  
- 目标系数向量 c（min c·x）  
- 约束矩阵 A 和右端项 b（A·x ≤ b）

**检验方法**  
- 检查 `result.status == 0`（有最优解）  
- 手动验证约束是否全部满足  
- 若 status != 0，分析是不可行（约束矛盾）还是无界（约束不够紧）

**代码入口**  
```python
from scipy.optimize import linprog
# min c @ x, s.t. A_ub @ x <= b_ub, A_eq @ x == b_eq
result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds)
if result.status == 0:
    print("最优解:", result.x, "最优值:", result.fun)
```

**容易踩的坑**  
- scipy.linprog 默认最小化，约束是 ≤；需求约束"≥"要乘 -1 转化  
- 变量是一维向量，矩阵要先 flatten，结果再 reshape

### 卡片 O-02｜整数规划 / 混合整数规划（IP/MILP）

**一句话定义**  
在线性规划基础上，要求部分或全部决策变量取整数值（含 0-1 变量）。

**适用条件**  
- 调配量必须是整件/整车（不能是小数）  
- 需要"是否选择某方案"的 0-1 决策（如是否开通某路线）  
- 题目明确要求整数解

**不适用场景**  
- 精度要求不高时（整数约束会显著增加计算时间）  
- 规模很大（节点数 > 100）时，商业求解器（Gurobi）才能可靠求解

**代码入口**  
```python
from pulp import *
prob = LpProblem("dispatch", LpMinimize)
x = LpVariable.dicts("x", [(i,j) for i in range(n) for j in range(m)],
                     lowBound=0, cat='Integer')  # 整数变量
# 或 cat='Binary' 表示 0-1 变量
prob += lpSum(cost[i][j]*x[(i,j)] for i in range(n) for j in range(m))
prob.solve()
print(LpStatus[prob.status])
```

### 卡片 O-03｜多目标优化

**一句话定义**  
同时优化两个或多个相互冲突的目标（如成本最小 vs 时间最短），求解 Pareto 前沿（最优权衡曲线）。

**适用条件**  
- 题目明确要求多目标权衡（如"综合考虑成本和效率"）  
- 需要展示不同目标之间的权衡关系  
- 作为进阶方案展示建模深度

**不适用场景**  
- 只有单一目标（不要为了"高级"而强行做多目标）  
- 计算资源有限时（多目标优化计算量更大）

**实现思路**  
- 加权法：将多个目标合并为一个加权和，权重需在假设中说明  
- ε-约束法：每次固定一个目标为约束，优化另一个，遍历多次得到 Pareto 前沿  
- NSGA-II 等遗传算法：适合复杂的多目标问题，但实现复杂

**检验方法**  
- 展示 Pareto 前沿图，说明每个点代表什么权衡  
- 选出推荐方案，说明推荐理由（如决策者更关注哪个目标）

---

### 卡片 O-04｜启发式算法（贪心/模拟退火/遗传算法）

**一句话定义**  
当问题规模大、精确求解困难时，用近似算法快速得到"足够好"的解（不保证最优）。

**适用条件**  
- 问题规模大，精确求解时间不可接受（如旅行商问题 TSP）  
- 约束复杂，难以写成线性规划标准形式  
- 题目明确允许近似解

**不适用场景**  
- 规模小的问题（精确求解更好）  
- 需要证明解是最优的（启发式只能给"好解"，不能保证最优）

**常见算法选择**  
- 贪心算法：每步选局部最优，实现简单，适合调度类问题的基准  
- 模拟退火（SA）：允许以一定概率接受较差解，跳出局部最优  
- 遗传算法（GA）：种群搜索，适合复杂多约束问题，但参数调整复杂

**检验方法**  
- 与精确解（小规模）或 LP 松弛（大规模）对比，说明"近似误差在 X% 以内"  
- 多次运行，看结果的稳定性（启发式有随机性）

### 卡片 M-01｜常微分方程（ODE）模型

**一句话定义**  
用微分方程描述变量随时间的连续变化规律，适合物理、生物、化学等有明确机理的动态问题。

**适用条件**  
- 问题有明确的机理（如传染病传播：易感→感染→康复的 SIR 模型）  
- 关注系统的动态演化过程  
- 可以从物理/化学/生物知识推导方程

**不适用场景**  
- 没有机理依据、纯数据驱动（→ 用机器学习）  
- 系统是离散的（→ 用差分方程）

**典型建模题型**  
- 人口增长（Logistic 模型）：dP/dt = r·P·(1 - P/K)  
- 传染病传播（SIR）：dS/dt = -β·S·I/N, dI/dt = β·S·I/N - γ·I, dR/dt = γ·I  
- 物质浓度变化（一阶反应）：dC/dt = -k·C

**关键参数**  
- 参数估计：通常需要用最优化方法（curve_fit 或最小二乘）拟合实际数据  
- 参数含义：每个参数必须有物理意义，不能只是数字

**检验方法**  
- 数值求解与实际数据对比（图形对比 + 误差指标）  
- 参数敏感性分析（参数小幅变化时，结果如何变化）  
- 稳定性分析（平衡点的稳定性）

**代码入口**  
```python
from scipy.integrate import odeint
import numpy as np

def sir_model(y, t, beta, gamma, N):
    S, I, R = y
    dS = -beta * S * I / N
    dI = beta * S * I / N - gamma * I
    dR = gamma * I
    return [dS, dI, dR]

t = np.linspace(0, 160, 160)
sol = odeint(sir_model, y0=[S0, I0, R0], t=t, args=(beta, gamma, N))
```

**容易踩的坑**  
- 参数取值没有依据，直接用"看起来合理"的数字  
- 没有把数值解和实际数据对比，只展示模拟结果

### 卡片 M-02｜差分方程模型

**一句话定义**  
用离散递推关系描述变量的逐步变化，是连续微分方程的离散版本，适合按时间步（天/周/年）变化的问题。

**适用条件**  
- 数据是离散的（每年、每月、每季度的数据）  
- 系统的状态按固定步长更新  
- 不需要连续时间分析

**典型形式**  
- 一阶线性差分方程：x_{t+1} = a·x_t + b  
- Logistic 差分：x_{t+1} = r·x_t·(1 - x_t)（可产生混沌行为）

**代码入口**  
```python
def simulate(x0, params, T):
    x = [x0]
    for t in range(T):
        x.append(model(x[-1], params))  # model 是你定义的递推关系
    return x
```
