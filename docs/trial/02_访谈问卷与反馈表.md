# 02 访谈问卷与反馈表

> 适用于：ModelingBridge / 模桥 · 免费试运行期  
> 包含：5 分钟快速访谈 · 15 分钟深度访谈 · 试用反馈表 · 统计模板 · 现场简版问卷

---

## 1. 5 分钟快速访谈提纲

适用于：招募阶段的初步了解，或周末课课前简短了解。

**说明语（30 秒）：**

> 我们在做数学建模学习辅助工具，想了解你真实的痛点。5 分钟，不做任何宣传，答案没有对错。

| # | 问题 | 目的 |
|---|------|------|
| Q1 | 你之前参加过数学建模竞赛吗？参加过哪种？ | 了解经历背景 |
| Q2 | 拿到建模题时，你通常第一步做什么？ | 了解现有习惯 |
| Q3 | 你最容易卡在哪个环节——读题、数据、选模型、写代码、画图、检验，还是写论文？ | 定位核心痛点 |
| Q4 | 如果有 AI 工具，你最希望它帮你做哪一件事？ | 了解期望 |
| Q5 | 你最担心 AI 工具出现什么问题？ | 了解顾虑 |

**记录要点：** 把 Q3 和 Q4 的原话尽量逐字记录，不要归纳成大类后再写。

## 2. 15 分钟深度访谈提纲

适用于：种子用户，或协会教学组成员。

### 开场说明（1 分钟）

> 我们在做一个数学建模学习辅助平台，叫模桥。它不代写、不保奖，只做一件事：帮你把"不知道从哪里开始"变成"有方向可以执行"。今天访谈是为了了解你真实的痛点，帮我们确认哪些功能值得先做，哪些可以不做。

### A. 背景了解（3 分钟）

| 问题 | 追问方向 |
|------|----------|
| 你参加过几次建模？参加过哪种竞赛？ | 校赛 / 国赛 / 美赛，是否拿过奖 |
| 你的 Python 和数学基础怎么样？ | 能独立写项目 / 能处理数据 / 只会基础语法 / 基本不会 |
| 你通常是一个人参赛还是组队？ | 分工是怎么做的 |
| 如果是教学组，你们目前怎么做新生培训？ | 有没有标准材料，痛点在哪 |

### B. 痛点挖掘（6 分钟）

**按流程逐步追问，不要跳环节：**

| 环节 | 追问 |
|------|------|
| 读题 | 看到一道新题时，你怎么判断它要你做什么？你会不会不知道每一问的"输出"是什么？ |
| 数据 | 你是怎么找数据的？有没有遇到题目数据不够用或不知道用什么数据的情况？ |
| 选模型 | 你通常怎么选模型？靠搜索、问同学、看论文，还是靠经验？你知道名字但不确定为什么用过吗？ |
| 写代码 | 最难的部分是哪里——数据处理、公式转代码、调参、还是结果解读？ |
| 画图 | 你知道应该画什么图吗？还是随便画？图注和论文位置你会提前想好吗？ |
| 检验 | 你知道结果跑出来之后还需要做哪些检验吗？比如灵敏度分析、交叉验证？ |
| 写论文 | 结果有了，论文是最难的吗？哪一章最卡？ |

**一定要追问的问题：**
- "你最崩溃的一次建模经历是什么时候？"（收集真实原话）
- "你当时是怎么解决的？最后的结果是什么？"

### C. 功能排序（3 分钟）

> 下面是我们第一版在考虑做的功能，请你从中选出你最希望先有的 3 个：

- AI 拆题工作台（读题→拆小问→确认）
- 模型推荐器（根据题型推荐基础/进阶模型）
- 数据需求表（列出你需要什么数据、从哪里来）
- 代码框架生成（给文件结构和函数骨架）
- 图表建议（推荐图表类型和图注）
- 模型检验清单（交叉验证、灵敏度分析等提醒）
- 论文结构助手（给章节框架，不写正文）
- 完整案例库（从题到论文结构的教学样例）

**追问：** 为什么选这 3 个？有没有哪个你绝对不需要？

### D. 协会/教学场景（仅对协会成员，2 分钟）

| 问题 | 目的 |
|------|------|
| 你们协会周末课一般怎么组织？ | 了解现有流程 |
| 备课时间和材料标准化是痛点吗？ | 确认协会需求 |
| 如果有可以直接用的案例库和工作台流程，你会考虑用吗？ | 测试接受度 |
| 你希望工具在哪些环节给新生最多的引导？ | 定位教学版优先级 |

### E. 试用意愿（1 分钟）

| 问题 | 选项 |
|------|------|
| 如果有 30—60 分钟的 Demo 试用，你愿意参加吗？ | 愿意 / 先看看 / 不愿意 |
| 你更喜欢线上 Demo 还是协会周末课现场？ | 线上 / 现场 / 都行 |
| 试用后你愿意提供一次 10 分钟的反馈访谈吗？ | 愿意 / 不一定 |
