# 08 试运行招募文案

> 适用范围：模桥（ModelingBridge）免费试运行阶段招募  
> 使用场景：微信群公告、朋友圈、协会官方通知  
> 使用原则：不夸大功能，不承诺结果，如实说明"免费 / 试运行 / 需要反馈"

---

## 一、受众分类与定位

| 受众 | 核心痛点 | 吸引点 |
|------|----------|--------|
| 建模新手 | 不知道从哪里开始、读题就卡住 | 有人带着走流程，不用一上来就看教程 |
| 会 Python 但建模弱 | 代码没问题，但不知道选什么模型 | 直接给模型方向 + 代码框架，跳过选型迷茫 |
| 协会教学组 | 想给学员找练习素材、想组织练习课 | 有完整案例库 + 教案模板，直接拿来上课 |
| 有参赛经验者 | 想练某类题型、想复盘自己的建模思路 | 可以对照平台的拆题思路，看哪里和自己不一样 |
