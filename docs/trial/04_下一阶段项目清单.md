## 4. 联合验收

| 验收项 | 标准 |
| --- | --- |
| 案例库 | 3 个案例均可在网页打开，且每个案例都含 10 个教学模块 |
| AI 工作台 | DeepSeek 与 MiMo 均能被选择；失败时自动回退演示模式 |
| 模型质量 | 已完成 3 道题轻量对比；正式试点前补到至少 5 道题 |
| 试点课 | 能用首页 + 工作台 + 案例库 + 反馈页完成 1 次 90 分钟试点 |
| 合规 | 页面和文档不出现保奖、代写、一键论文、自动参赛等宣传表达 |
| 反馈 | 至少能收集并导出 20 条有效反馈 |

## 5. 下一次迭代建议顺序

1. ClaudeCode：准备 5 道评测题和试点课流程。
2. Codex：用扩展评测题继续跑 DeepSeek / MiMo 对比，记录差异。
3. Codex：做移动端和试点课现场流程演练。
4. ClaudeCode：根据对比结果优化提示词和案例解释。
5. Codex：做一次完整本地演练，确认试点课流程能跑通。
