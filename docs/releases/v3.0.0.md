## 一句话

五门互动精讲（线性规划、图论、回归、AHP、TOPSIS）+ AI 建模技能包 + 赛事日历 + 招新小游戏，组成从“测一测”到“学一门”再到“做一道题”的完整学习闭环。

## 给新生的入口

1. 扫码进入 `/challenge`，3 分钟测出自己是哪种建模人格，结果页直接推荐一门课。
2. 精讲目录顶部“从哪里开始”：先学线性规划，再按兴趣选优化、预测、评价中的一条线。
3. 每门课读完做专项练习，答错会告诉你错在哪、该回看哪一节。
4. 想完整走一道题：七关实战；需要用 AI 时：AI 建模技能包；想知道什么时候报名：赛事日历。
