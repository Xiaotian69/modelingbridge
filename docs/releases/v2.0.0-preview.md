## 已知限制

1. **没有在线 AI**：教练提示与帮助梯子均为课程预置内容；AI 工作台需要后端，线上静态版本只能看流程（页面已注明）。
2. **只有 1 个完整精讲专题**（线性规划）；其他 7 种方法仅有速查卡，标“精讲筹备中”。
3. **学习数据只存在本机浏览器**：无账号、无跨设备同步；无痕模式或清除站点数据会丢失；暂不支持从导出文件恢复。
4. **提示词库**：9 条原创模板均标“待复核”（作者已自查，尚未经负责人审核），负责人审核后改为“已审核”；暂无按比赛筛选（均为通用模板）；七关内为链接跳转，侧板以后做。
5. **资料索引**：只含原创内容与官方链接；第三方赛题 / 论文合集未核实授权，不列出、不提供下载。
6. **赛事日历**：时间信息以各赛事官网为准；“生成计划”无后端时使用本地规则生成。
7. **域名**：`modelingbridge.cc`（不带 www）目前解析到域名商停放页，不是本站（见上线方案第 6 节）；请对外使用 `https://www.modelingbridge.cc`。
8. 首屏开屏动画在极少数低端设备上会自动简化。
