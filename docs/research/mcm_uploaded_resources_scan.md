## 2. 接入策略

1. 不在前端批量展开 PDF 或压缩包，先做索引与教学化摘要。
2. 真题只做“题型标签、训练目标、简化任务、推荐模型”整理，不搬运完整题面。
3. 优秀论文只拆结构、方法、图表和表达技巧，不复制长段正文。
4. Prompt 资料需要合规清洗：保留学习辅助、拆题、检查、解释；去掉代写、保奖、一键成文表达。

## 3. 交给 ClaudeCode 的拆解任务

- 从 2000-2024 美赛题库中先选 20 道经典题，整理到 `docs/research/mcm_classic_problem_index.md`。
- 从 2006-2025 优秀论文中先选 10 篇，整理摘要结构、模型路线、图表表达和可借鉴写法，写到 `docs/research/mcm_outstanding_paper_patterns.md`。
- 从 Prompt 资料中提炼合规提示词，写到 `docs/content/ai_tutor_prompts.md`。
