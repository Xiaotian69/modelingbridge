### C-01｜2011A：城市交巡警服务平台的设置与调度

| 项目 | 内容 |
|------|------|
| 年份 / 赛事 | CUMCM 2011 A 题 |
| 题型 | 选址 + 网络优化 + 调度 |
| 难度建议 | 冲奖挑战（可简化为进阶训练） |

**为什么经典**：覆盖"地图建模→服务半径约束→最短响应路径→资源调度"完整链路。数据以路口节点和道路时间给出，要求选手自己建图。任何有网络流或规划背景的同学来看都能有收获。

**适合训练的模型**：网络流、线性规划（MILP）、聚类（服务区划分）

**简化版任务**：给定 8 个路口、6 条道路（权为行驶分钟）和 2 辆警车，规划服务平台位置，使所有路口的最大响应时间最短。交付：平台节点、覆盖图、响应时间分布表。

**参考来源**：[CUMCM 历年题目索引](https://www.mcm.edu.cn/html_cn/node/a1ffc4f5587c8a6f96be4a9d690277ef.html)

### C-02｜2012A：葡萄酒的评价

| 项目 | 内容 |
|------|------|
| 年份 / 赛事 | CUMCM 2012 A 题 |
| 题型 | 综合评价 + 统计检验 |
| 难度建议 | 进阶训练 |

**为什么经典**：评价类题目的教科书。含"评委打分一致性检验→指标筛选→主客观权重结合→排名稳健性"四个标准步骤，每个环节都有方法可选，很适合对比不同方法的优劣。

**适合训练的模型**：熵权法 + TOPSIS、AHP、回归（指标相关性分析）

**简化版任务**：10款葡萄酒，3位评委各打10分制分数，外加3个理化指标（酸度、糖分、单宁）。判断三位评委的打分是否一致（Kendall W或Spearman相关）；建立综合评分模型；检验第1名和第2名的差距是否显著。

**参考来源**：[CUMCM 历年题目索引](https://www.mcm.edu.cn/html_cn/node/a1ffc4f5587c8a6f96be4a9d690277ef.html)

### C-03｜2013A：车道被占用对城市道路通行能力的影响

| 项目 | 内容 |
|------|------|
| 年份 / 赛事 | CUMCM 2013 A 题 |
| 题型 | 交通流机理建模 + 数据拟合 |
| 难度建议 | 进阶训练 |

**为什么经典**：把交通流量–密度–速度关系转化成机理方程，再用实测视频数据拟合参数。是"机理方程 + 数据校准"组合建模的典型，强调物理含义而非黑箱拟合。

**适合训练的模型**：差分方程 / 流量方程（Greenshields 模型或 LWR 方程）、回归

**简化版任务**：给定某路段每分钟的车流量观测值（正常状态 vs 一条车道被占），建立简化交通流方程，估算车道被占后通行能力下降百分比，并给出"车辆行驶速度与密度"关系图。

**参考来源**：[CUMCM 历年题目索引](https://www.mcm.edu.cn/html_cn/node/a1ffc4f5587c8a6f96be4a9d690277ef.html)

### C-04｜2013B：碎纸片的拼接复原

| 项目 | 内容 |
|------|------|
| 年份 / 赛事 | CUMCM 2013 B 题 |
| 题型 | 图像相似度量化 + 组合优化 |
| 难度建议 | 进阶训练（需图像处理基础） |

**为什么经典**：把图像相似度转化为目标函数，再用排列组合的搜索方法找最优拼接顺序。覆盖"量化→优化→验证"链路，且有明确的正确答案可自验证，是少见的"能自检"的竞赛题。

**适合训练的模型**：组合优化（穷举、贪心、遗传算法）、聚类（边缘相似性分组）

**简化版任务**：5张等宽纸条，每条高度相同，给定各条右边缘和左边缘的灰度值。以相邻边缘灰度差之和为代价函数，用穷举或贪心排列出最优拼接顺序。

**参考来源**：[CUMCM 历年题目索引](https://www.mcm.edu.cn/html_cn/node/a1ffc4f5587c8a6f96be4a9d690277ef.html)

### C-05｜2014A：嫦娥三号软着陆轨道设计与控制策略

| 项目 | 内容 |
|------|------|
| 年份 / 赛事 | CUMCM 2014 A 题 |
| 题型 | 机理建模 + 最优控制 |
| 难度建议 | 冲奖挑战 |

**为什么经典**：状态变量（高度、速度、燃料）、物理约束（推力上限、着陆速度=0）、目标函数（最省燃料）三要素俱全，是学习机理建模"从物理方程到数学问题"转化过程的教科书。

**适合训练的模型**：常微分方程（ODE）、线性规划（离散化后）

**简化版任务**：二维平面，飞行器从高度 H=1000m、水平速度 v₀=200m/s 开始减速。重力 g=1.6m/s²（月球），发动机推力 F 可变（0≤F≤10000N），飞行器质量 m=1000kg。设计控制策略使飞行器以垂直速度≤1m/s、水平速度=0安全着陆，并尽量省燃料。

**参考来源**：[CUMCM 历年题目索引](https://www.mcm.edu.cn/html_cn/node/a1ffc4f5587c8a6f96be4a9d690277ef.html)

| 项目 | 内容 |
|------|------|
| 年份 / 赛事 | CUMCM 2015 A 题 |

|------|------|
| 年份 / 赛事 | CUMCM 2016 A 题 |
| 题型 | 物理机理建模 + 参数优化 |
| 难度建议 | 冲奖挑战 |

**为什么经典**：纯物理机理推导，从力平衡方程建立联立方程组，再调整参数（锚链长度、节点重量）使系统满足约束（倾斜角不超标）。考验数理基础和建模严谨性。

### C-09｜2018A：高压油管的压力控制

| 项目 | 内容 |
|------|------|
| 年份 / 赛事 | CUMCM 2018 A 题 |
| 题型 | 机理建模 + 参数拟合 + 情景优化 |

### C-10｜2018B：智能 RGV 的动态调度策略

| 项目 | 内容 |
|------|------|
| 年份 / 赛事 | CUMCM 2018 B 题 |
| 题型 | 动态调度 + 整数规划 / 仿真 |
| 难度建议 | 进阶训练 |

### C-13｜2022C：古代玻璃制品的成分分析与鉴别

| 项目 | 内容 |
|------|------|
| 年份 / 赛事 | CUMCM 2022 C 题 |
| 题型 | 统计分析 + 聚类 + 分类 |
| 难度建议 | 进阶训练 |

**为什么经典**：实验科学数据驱动建模，含假设检验（成分差异显著性）、聚类（自动发现玻璃类型）、分类（未知样品鉴别）。数据干净，步骤清晰，是统计建模入门的好题。

**适合训练的模型**：聚类（K-Means、层次聚类）、随机森林（分类）、统计检验（t-test、ANOVA）

**简化版任务**：30件玻璃样品，每件测定8种化学成分含量（含缺失值）。处理缺失值后，聚类分析发现玻璃的自然分组；对比两类玻璃在各成分上的差异显著性；用随机森林建立分类器，对5件未知样品判断类别。

**参考来源**：[CUMCM 历年题目索引](https://www.mcm.edu.cn/html_cn/node/a1ffc4f5587c8a6f96be4a9d690277ef.html)

## 三、其他赛事典型题型

### O-01｜MathorCup 典型题：零售商品库存与补货优化

| 项目 | 内容 |
|------|------|
| 赛事类型 | MathorCup 数学应用挑战赛（历年常见题型） |
| 题型 | 需求预测 + 库存管理 + 随机规划 |
| 难度建议 | 进阶训练 |

**为什么经典**：MathorCup 偏重产业应用，库存补货是运筹学中"报童问题"的现实扩展，强调需求不确定性下的最优决策。

**适合训练的模型**：回归 / 时间序列（需求预测）、随机规划或情景分析（不确定需求处理）

**简化版任务**：某超市5种商品，给定过去30天销售数据，建立需求预测模型。对每种商品确定补货量 q，使期望总成本（库存成本 + 缺货损失）最小。用 100 次蒙特卡洛模拟验证策略效果。

**参考来源**：[MathorCup 官网](https://www.mathorcup.org/)，历年竞赛题目页

### O-02｜五一杯典型题：应急资源调配

| 项目 | 内容 |
|------|------|
| 赛事类型 | 五一数学建模联赛（历年常见题型） |
| 题型 | 运输优化 + 整数规划 |
| 难度建议 | 入门改编 |

**为什么经典**：五一杯常见的运筹类题型，结构清晰，适合新手练习从"现实问题→决策变量→约束→求解→验证"的完整流程。

**适合训练的模型**：线性规划（LP / MILP）、网络流

**简化版任务**：3个物资仓库（库存分别为100、80、60单位），5个受灾点（需求分别为40、50、60、35、55单位），给定运输费用矩阵。最小化总运输成本，满足所有需求，不超过仓库库存。

**参考来源**：[大学生数学竞赛网](https://www.cmathc.org.cn)

### O-03｜华数杯典型题：多指标综合评价

| 项目 | 内容 |
|------|------|
| 赛事类型 | 华数杯国际大学生数学建模竞赛（历年常见题型） |
| 题型 | 数据清洗 + 综合评价 |
| 难度建议 | 入门改编 |

**为什么经典**：华数杯注重数据处理能力，综合评价题目常包含缺失值、异常值，比纯净数据的 TOPSIS 更贴近真实数据场景。

**适合训练的模型**：熵权法 + TOPSIS、AHP、聚类

**简化版任务**：15个城市，10项指标（含 2 项有缺失值、1 项有离群点）。完成数据清洗（说明处理方法）后，建立综合评价模型排名，对比用缺失值处理前后结果的差异。

**参考来源**：[华数杯官网](https://www.hisac.net/)（注：具体题目以当年通知为准）

### O-04｜APMCM 典型题：可持续发展综合评估

| 项目 | 内容 |
|------|------|
| 赛事类型 | APMCM 亚太地区大学生数学建模竞赛（历年常见题型） |
| 题型 | 多层次评价体系 + 情景预测 |
| 难度建议 | 进阶训练 |

**为什么经典**：APMCM 偏重可持续发展主题，多层次指标（经济/环境/社会）的权重设计和情景预测是该类题目的核心难点。

**适合训练的模型**：AHP（层次权重）、熵权 + TOPSIS（综合评分）、时间序列（指标预测）

**简化版任务**：10个亚太城市，设计3个维度（经济活力、环境质量、社会公平），每维度3个指标。用 AHP 设计层次权重，TOPSIS 给出综合排名。再用时间序列预测每个城市10年后的关键指标值，判断排名可能的变化。

**参考来源**：[APMCM 官网](https://www.apmcm.org/)
