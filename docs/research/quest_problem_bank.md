> 来源说明：国赛题目索引自 [CUMCM 官网](https://www.mcm.edu.cn)；美赛题目索引自 [COMAP](https://www.comap.com/contests/mcm-icm)；公开可检索，题面请从官方渠道获取

## 使用方式

- **适合哪几关训练**：标签说明这道题最适合练哪几个关卡，不必做完全部 7 关
- **核心模型**：该题目最常用的模型，供关卡 4 选题参考
- **难度建议**：适合不同程度学生的使用方式
- **简化版任务**：如果不想用原题数据，可以用简化场景独立练习

|------|------|
| 年份 / 赛事 | CUMCM 2013 B 题 |
| 题型 | 图像处理 + 组合优化（边缘匹配） |

## 二、评价类题目

### E-01｜CUMCM 2012A：葡萄酒的评价

| 项目 | 内容 |
|------|------|
| 年份 / 赛事 | CUMCM 2012 A 题 |
| 题型 | 综合评价 + 统计检验 |
| 难度建议 | 进阶训练 |
