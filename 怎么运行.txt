========================================
  数模网站（模桥）—— 最简运行办法
========================================

【事先准备】电脑上需要已安装：
  1）Python 3.11 或更高版本  https://www.python.org/downloads/
     安装时务必勾选：Add python.exe to PATH
  2）Node.js（LTS 长期支持版即可）  https://nodejs.org/

----------------------------------------
【重要：不要自己敲命令】
----------------------------------------

请不要在项目根目录（数模网站开发）里运行 npm，否则会提示找不到 package.json。
正确做法：只双击下面两个 bat，它们会自动进入 frontend / backend 文件夹。

----------------------------------------
【只要记 3 步】
----------------------------------------

第 1 步：双击运行「启动后端.bat」
        → 会弹出一个黑色窗口，第一次会多等一会儿（装依赖）
        → 看到 Backend: http://127.0.0.1:8000 就对了
        → 这个窗口要一直开着，不要关

第 2 步：再双击运行「启动前端.bat」
        → 又会弹出一个黑色窗口，第一次也会装依赖
        → 里面会出现一行网址，一般是：http://127.0.0.1:5173/

第 3 步：用浏览器（Chrome / Edge）打开上面的网址
        → 就能看到网站首页

----------------------------------------
【若黑色窗口里全是乱码、报「不是内部或外部命令」】
----------------------------------------

这是因为 Windows 的 CMD 默认编码与脚本编码不一致。
已把「启动后端.bat」「启动前端.bat」改成纯英文提示，请用仓库里最新版覆盖后再双击。

----------------------------------------
【容易错的地方】
----------------------------------------

· 两个 bat 都要开着：先开的叫后端，后开的叫前端，关掉任意一个网站都会不正常。

· 如果浏览器里点「开始分析」报错：多半是后端没启动，或后端窗口被关了。
  可先单独在浏览器打开：http://127.0.0.1:8000/api/health
  若能看到 {"ok":true} 说明后端正常。

· 不配大模型密钥也能用：工作台会走「演示模式」结构化结果，用来熟悉流程。

----------------------------------------
【想配大模型时（可选）】
----------------------------------------

在文件夹「backend」里新建文本文件，改名为 .env（注意前面有个点），写入：

LLM_API_KEY=你的密钥
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat

保存后，关掉后端窗口，再重新双击「启动后端.bat」。
